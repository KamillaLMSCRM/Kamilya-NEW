# Training operational status V1

## Назначение

Дополнить канонический журнал обучения двумя независимыми операционными
сигналами без новой таблицы и без записи состояния:

1. `assignment_due_at` и `deadline_state` — фактический срок конкретного
   назначения. Явный `EnrollmentAccessPolicy.due_at` имеет приоритет над
   допустимым сроком повторного цикла.
2. `certificate_expires_at` и `certificate_status` — срок и состояние
   последнего выданного сертификата конкретного enrollment.

## Инварианты

- Существующие `cycle_due_at`, `deadline_status`, overdue-фильтр и overdue
  count остаются привязаны только к неизменяемому повторному циклу.
- Разовый срок назначения не маскирует просроченный повторный цикл.
- Строка без срока получает `deadline_state=none`, а не успокаивающий
  «в срок».
- Последний сертификат выбирается детерминированно по `issued_at DESC, id DESC`;
  его отзыв имеет приоритет над сроком действия.
- `expiring` означает срок в пределах следующих 30 дней включительно.
- Join к policy, enrollment, certificate, user и course обязательно содержит
  tenant и точную identity назначения; существующий RLS/FORCE RLS сохраняется.

## Проверка

- Unit: граничные даты, 30-дневное окно, SQL tenant/exact-enrollment contract.
- Integration: приоритет policy, независимость cycle status/filter/count,
  несколько сертификатов одного enrollment, legacy-строка без срока.
- Frontend: mobile/desktop parity, локализация статусов, отсутствие
  успокаивающего badge при неизвестном состоянии.
- Production: только синтетический tenant; проверка экрана циклов и журнала
  после точного SHA/readback.

## Rollback

Миграции нет. Откат приложения удаляет дополнительные поля и экран, не изменяя
существующие назначения, циклы, сертификаты и историю уведомлений.
