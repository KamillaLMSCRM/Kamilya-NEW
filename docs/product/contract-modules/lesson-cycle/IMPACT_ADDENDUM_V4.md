# Lesson-cycle semantic contracts V4

Status: accepted for the same bounded DEV experiment, owner instruction2026-10-21.
This does not authorize default/shared-worker or production rollout.

- Typed author intent: rule / scenario / threshold. A percentage-boundary item
  includes the comparison operator and unit, has an explicit boundary stem and
  numeric point choices. Rendering values as percentages is deterministic;
  no comparison operator is stripped from a freeform answer.
- The blind key must match the same source-quoted numeric boundary AND operator.
  Broad sufficient-condition items keep the conservative overlap gate.
- Bind added priority/simultaneity to the correct option's exact source evidence;
  a model consensus cannot add those predicates. Missing calendar applicability
  is review-required: Saturday/Sunday alone is not a local work schedule.
- Pilot operational targets for income and amendment conditions become atomic.
  Question-specific coverage proof must quote the stem and/or correct option;
  independent manual review still determines whether each objective is assessed.
- Snapshot identity includes V4 and the typed envelope; old results are not
  reused. Checkpoint replay rechecks intent, numerical and temporal contracts.
- Existing normal three-call / maximum six-call bound remains unchanged.

Limitations: RU safety patterns cover confirmed error classes, not all possible
semantic paraphrases. Typed numeric proof covers percentages, not all arithmetic.
New source content may still require human review. The experiment must include
fresh source-based review and exact-defect replay; green unit tests alone are not
semantic acceptance. Same finished lesson texts and frozen baseline are retained;
the atomic manual oracle is versioned, not mislabeled as automatic extraction.

V5 refines the same contract after the fresh V4 experiment: numeric boundaries
also support calendar days and months, with source-bound operators and canonical
point rendering. AND/OR branches require an explicit full-set question instead
of falsely rejecting one allowed branch. A prescribed consent decision may not
be downgraded into mere permission. Maximum six model calls remains unchanged.
The V4 partial CRUD save was reconciled by exact prefix readback and completing
only absent questions, not regeneration or blind POST retry; original error
status was not captured. Later runs preserve bounded sanitized API error codes.

V6 corrects a validator false negative: multiple exact proof fragments for ONE
objective are allowed, but count as one objective only. Numeric repair explicitly
distinguishes a boundary from a satisfying example; counterexample audit must
not invent a new attachment of an OR clause without grammatical evidence. The
DEV comparison adapter respects the existing quiz burst window by pacing writes;
no limiter configuration is changed. Selective case repetitions retain lineage.

V7 replaces model-copied evidence with server-issued passage references. Source
and finished-lesson lines remain in order with their full text; selecting a ref
resolves the exact source substring on the server. Unknown/conflicting refs fail.
The audit uses one explicit semantic admit/veto plus reason and target proofs,
not three redundant flags from the same verdict. Explicit contradictory legacy
flags still veto. Several proof fragments count as one target. No logical check
or typed boundary gate is waived; literal proof rendering becomes deterministic.
Calendar/priority guards remain conservative. A months boundary cannot be renamed
as an overall loan/contract duration without quoted support for that owner.

V8 adds optional caller-verified applicability to LearningTarget (default empty).
Every candidate claiming that target receives the exact context prefix BEFORE
blind review and counterexample audit. Conflicting contexts in one candidate
fail; checkpoint resume checks the stable prefix. This prevents loss of the
inside/outside-settlement scope in the approval pilot, without asking the model
to remember it. The pilot context is manually source-checked; automatic grounded
context extraction remains a default-integration prerequisite, not claimed done.

V9 renders a missing percent-unit label from the explicit typed numeric contract.
Only the unit is added before review; values/operators/key are not changed or
stripped. Resume renders it once. The source boundary/operator proof is unchanged.

V10 adds optional target.question_format:full_set, rendered as an explicit
instruction before both model reviews. Complete allowed-branch coverage must not
depend on a freeform author's wording. The same full-set and numeric checks
still apply. Snapshot identity includes this input; no key or source text changes.

V11 adds optional caller/source-verified answer requirement groups. Each group
contains alternative literal stems (not executable regex); all groups must occur
in the correct answer for claimed target coverage. Missing critical timing or
recipient information cannot be masked by quoting a complete source paragraph
or placing it in the stem. This is a negative omission guard, NOT a logical
entailment proof; blind semantic and counterexample reviews still apply. Pilot
rubrics remain manual, not claimed as automatic original-document extraction.
Context/full-set headers compose idempotently and exact duplicate instructions
are removed before the canonical header is rendered; answers are not rewritten.
