## Условие коммерческого запуска

До подключения коммерческого клиента необходимо подтвердить:

1. размещение основной PostgreSQL/pgvector, файлового хранилища, зашифрованных резервных копий, CRM, очереди/кэша, OCR/воркеров и журналов с персональными данными в Казахстане;
2. фактических привлечённых обработчиков, их юридические лица, регионы, цели, категории данных, гарантии передачи и сроки хранения;
3. отсутствие в коммерческом контуре переходного хранилища за пределами РК без раскрытого основания;
4. согласованную конфигурацию внешней обработки ИИ/LLM.

Переходная среда разработки или пилота не описывается как уже размещённая в Казахстане.
