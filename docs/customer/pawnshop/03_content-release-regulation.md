# Регламент публикации и версий учебных материалов

## 1. Цель

Регламент гарантирует, что работник проходит именно ту редакцию программы, которая была утверждена для его назначения, а последующие изменения не переписывают историю завершенной попытки.

## 2. Жизненный цикл версии

`Черновик -> На рецензии -> На утверждении -> Опубликована -> Архивная`.

| Статус | Кто может менять | Результат |
|---|---|---|
| Черновик | методолог | подготовка материала и теста |
| На рецензии | методолог, рецензент | проверка содержания и источников |
| На утверждении | утверждающий | решение о публикации |
| Опубликована | только утверждающий по правилам версии | доступна для назначения |
| Архивная | владелец процесса | не назначается новым сотрудникам, история сохраняется |

## 4. Порядок изменения

Существенное изменение содержания создает новую версию. Новая версия не меняет назначения и результаты по старой версии. Срочное исправление ошибки документируется причиной и отдельной записью утверждения.

## 5. Контроль перед публикацией

- источник доступен и относится к выбранной области;
- нет материалов другой организации без правового основания;
- проверены должности и аудитория;
- проверены тесты, ответы и порог;
- определены дата вступления и срок актуальности;
- утверждающий подтвердил публикацию.
