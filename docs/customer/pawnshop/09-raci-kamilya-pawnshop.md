# RACI: Kamilya, ломбард и внешний контур

Обозначения: **R** выполняет, **A** утверждает/несет ответственность, **C** консультирует, **I** информируется.

| Работа | Kamilya | Ломбард | Внешний контур |
|---|---|---|---|
| Настройка tenant и ролей | R | A | I |
| Определение обязательных должностей и программ | C | A/R | C |
| Подготовка содержания курса | R | A/C | C |
| Проверка нормативной применимости | C | A/R | C |
| Утверждение программы | I | A/R | I |
| Публикация версии | R | A | I |
| Назначение сотрудникам | R | A | I |
| Прохождение и тест | R (платформа) | R (работник) | I |
| Пересдача и апелляция | C/R (инструмент) | A/R (решение) | C при необходимости |
| Комиссия/допуск | I/C | A/R | R если внешняя процедура |
| Журнал и evidence export | R | A/R (использование и хранение) | I/C |
| Legal hold | C (техническая реализация) | A/R | C |
| Персональные данные и основания обработки | C | A/R | C |
| Инцидент платформы | A/R по сервису | C/R по бизнес-процессу | C при затрагивании |
| Официальный тест или государственный реестр | I | A/R | A/R |

## Граница обещания

Kamilya предоставляет платформу, настройку процесса, шаблоны, evidence export и сопровождение пилота. Ломбард утверждает содержание, обязательность, роли, сроки, последствия и юридическую квалификацию результата. Внешний контур подключается только там, где требуется отдельная организация, государственная система, комиссия, ЭЦП или специальный регламент.
