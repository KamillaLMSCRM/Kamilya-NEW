# Пакет внедрения Kamilya LMS для ломбарда

Статус: проект для согласования и заполнения. Версия: 0.1. Дата: 31.07.2026.

## Назначение

Этот пакет дает ломбарду готовую основу для запуска внутреннего электронного обучения, проверки знаний и документирования результатов в Kamilya LMS. Он не заявляет, что внутренний тест заменяет официальный тест АФМ, государственную аттестацию, ЭЦП или иное специальное требование. Специальные режимы включаются только после отдельного решения и проверки применимой процедуры.

## Порядок внедрения

1. Назначить владельца процесса от ломбарда и утвердить перечень должностей первого пилота.
2. Заполнить матрицу `04_role-program-periodicity-matrix.md`: должность, программа, периодичность, контрольный результат.
3. Согласовать и подписать приказ о внедрении из `01_order-lms-implementation.md`.
4. Утвердить положение об электронном обучении из `02_e-learning-regulation.md`.
5. Согласовать порядок публикации материалов и версий из `03_content-release-regulation.md`.
6. Назначить программы сотрудникам или подразделениям в Kamilya; методолог публикует только утвержденные версии.
7. Провести пилот на 2-5 сотрудниках: назначение, прохождение, проверка знаний, пересдача при необходимости, формирование журнала и evidence export.
8. Согласовать форму внутреннего акта/протокола по `06_journal-act-evidence-regulation.md`.
9. Утвердить сроки хранения и legal hold из `07_retention-legal-hold-policy.md`.
10. Подписать итоговый acceptance record: список программ, сотрудники, версии, результаты, выявленные ограничения.

## Что является обязательным, рекомендуемым и условным

| Категория | В этом пакете | Правило |
|---|---|---|
| База внедрения | обучение, назначение, версия материала, тест, журнал, экспорт | рекомендуется утвердить для пилота |
| Нормативно обусловленный контур | обучение customer-facing сотрудников, актуальные методические материалы, ИБ-onboarding в применимой части | проверить применимость к конкретному процессу ломбарда |
| Условный контур | комиссия, аттестация, допуск, ЭЦП, специальные журналы ОТ/пожарной безопасности, официальный тест АФМ | не включать названием или кнопкой без решения юриста/комплаенса |
