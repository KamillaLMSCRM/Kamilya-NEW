# Поисковый спрос в Казахстане: LMS и обучение сотрудников

Дата среза: 2026-08-07  
Рынок: Казахстан  
Основной язык: русский; казахский — отдельный exploratory-тест

## Итог

Для первой рекламной и SEO-проверки берём не узкое обещание «курс из PDF», а задачу клиента: обучение и проверка знаний сотрудников. Самые рабочие кластеры:

1. **Платформа для обучения сотрудников** — наиболее прямое совпадение с ценностью Kamilya.
2. **Система обучения персонала / обучения и развития персонала** — деловой язык руководителей и HR.
3. **LMS / система управления обучением** — категорийный спрос, но с риском мусора из-за других значений «LMS».
4. **Онбординг и адаптация сотрудников** — отдельный сценарий с понятным бизнес-результатом.
5. **Тестирование и учёт обучения сотрудников** — функциональный спрос с более узким охватом.

«Обучение сотрудников ломбарда», «курс по микрокредитованию» и «генерация курса из PDF» пока не получили сигнала в локальных подсказках. Их следует использовать как отраслевые страницы, демо-сценарии и рекламные гипотезы после проверки объёма, а не как основу первой кампании.

## Как собирался сигнал

- Собраны подсказки Google Autocomplete с параметрами `gl=kz`, `hl=ru` для русских и `gl=kz`, `hl=kk` для казахских запросов.
- Сверены формулировки и позиционирование локальных LMS-поставщиков: [Smart LMS](https://edu.lms.kz/), [MyTeamHR LMS](https://myteamhr.kz/solution/lms), [WellDone](https://well-done.kz/).
- Отдельно проверен отраслевой кейс [онлайн-академии для М-Ломбард](https://well-done.kz/m-lombard): наличие кейса подтверждает прикладной спрос в ломбардах, но не является статистикой поисковых запросов.
- Автодополнение — только прокси популярности и способ расширить семантику. Оно **не заменяет месячный объём**. Точный объём, конкуренцию и CPC нужно снять в Keyword Planner: [официальное описание прогнозов](https://support.google.com/google-ads/answer/3022575?hl=ru) и [инструкция по планированию ключевых слов](https://support.google.com/google-ads/answer/7337243?hl=ru).

## Рекомендуемая структура проверки рекламы

### Кампания 1 — «Обучение сотрудников» (P1)

Группа `Платформа`: `платформа для обучения сотрудников`, `онлайн платформа для обучения сотрудников`.  
Группа `Система`: `система обучения персонала`, `система обучения персонала в организации`, `система обучения и развития персонала`.

### Кампания 2 — «LMS Казахстан» (P1/P2)

Группа `LMS`: `LMS система управления обучением`, `LMS система обучения`, `LMS для бизнеса`.  
Группа `KZ`: `LMS Казахстан`, `LMS в Казахстане`.

### Кампания 3 — «Онбординг и контроль» (P2)

Группа `Онбординг`: `онбординг новых сотрудников`, `онбординг и адаптация сотрудников`, `платформа для адаптации сотрудников`.  
Группа `Контроль знаний`: `тестирование персонала онлайн`, `система тестирования сотрудников`, `учёт обучения сотрудников`.

Ключи запускаем только в phrase/exact match. Широкое соответствие не используем на первом срезе: у `LMS` есть нерелевантные значения (например, автомобили и детали), а у информационных запросов ниже коммерческая определённость.

## Минус-слова первого слоя

Добавить на уровне кампаний: `школа`, `университет`, `студент`, `школьник`, `учитель`, `репетитор`, `дети`, `курсовая`, `диплом`, `вакансия`, `работа`, `бесплатно`, `бесплатные курсы`, `создать онлайн школу`, `учебный центр`, `Moodle`, `LMS 901`, `Audi`, `автомобиль`, `запчасти`.

Перед запуском проверить отчёт поисковых запросов и расширить список фактическими нерелевантными вариантами. `курс`, `обучение`, `персонал` и `сотрудники` не добавлять в минус-слова: они нужны целевым группам.

## Что меняем на лендинге

- Главный экран оставляем в формулировке **«LMS-система для обучения сотрудников в Казахстане»** — она одновременно покрывает категорию, задачу и географию.
- В блоке для руководителя явно показать результат: единые правила обучения, контроль прохождения и отчётность по подразделениям.
- В блоке для исполнителя показать путь: документ/материал → короткий курс → тест → обратная связь → сертификат.
- `Курс из PDF` и отраслевой сценарий ломбарда использовать как доказательство скорости запуска, но не делать заголовком, пока Planner не подтвердит отдельный спрос.
- Для казахского языка подготовить локализованный вариант страницы и провести отдельный малобюджетный тест: подсказки `қызметкерлерді оқыту платформасы`, `қызметкерлерді онлайн оқыту`, `персоналды оқыту жүйесі` не дали устойчивых вариантов, поэтому заранее считать этот канал гипотезой.

## Процедура подтверждения в Keyword Planner

1. География: Казахстан; язык: русский, затем отдельный прогон казахского; сеть: только Google Search.
2. Загрузить список из [CSV](./kz-google-ads-keywords-2026-08-07.csv), добавить варианты с коммерческими модификаторами из отчёта.
3. Для каждого кластера сохранить среднее число запросов за 12 месяцев, последние 3–6 месяцев, конкуренцию и диапазон CPC.
4. Отдельно отметить сезонность и долю мобильного трафика; не смешивать прогноз кликов с фактическим объёмом запросов.
5. Перенести в запуск только P1/P2 с подтверждённым объёмом и приемлемым CPC. P3 оставить в backlog.
6. Через 7–14 дней оценивать не клики, а квалифицированные заявки: отрасль, размер команды, наличие обязательного обучения, готовность к пилоту.

## Критерии решения после теста

- **Оставить кластер:** есть показы, запрос соответствует B2B-задаче, доля квалифицированных лидов не ниже основной кампании.
- **Уточнить объявление/страницу:** показы есть, но лиды слабые — значит, запрос шире обещания или не хватает отраслевого доказательства.
- **Убрать:** нет показов после подтверждения Planner либо преобладает нерелевантный интент.

Примечание: публичные страницы конкурентов и отраслевые кейсы помогают выбрать язык и сегменты, но не доказывают объём спроса. Числа объёма добавляем только после выгрузки из аккаунта Google Ads.
