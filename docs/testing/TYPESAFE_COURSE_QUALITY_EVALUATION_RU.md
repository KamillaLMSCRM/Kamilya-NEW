# Оценка качества генерации курса через TypeSafe

## Назначение и граница

Этот инструмент — **только локальный контур разработки**. Он оценивает уже
сохранённый JSON-артефакт курса и тестов, чтобы сравнивать версии генератора,
находить неоднозначные ответы, слабые дистракторы и неподтверждённые источником
формулировки.

TypeSafe не входит в API Kamilya, web-приложение, Celery-задачи или клиентский
путь генерации. Отказ TypeSafe не влияет на загрузку документа, генерацию,
редактирование и публикацию курса. Автоматический тест проверяет отсутствие
`TYPESAFE_API_KEY`, `api.typesafe.ai` и импортов evaluator в production-коде.

## Что отправляется

Один запрос содержит только один сфокусированный объект:

- для урока — относящийся к нему фрагмент источника, цели, заголовок и текст;
- для вопроса — относящийся фрагмент источника, вопрос, варианты, ключ и
  пояснение.

Перед первым сетевым вызовом весь артефакт проходит локальный privacy-preflight.
Email, телефон и 12-значная последовательность, похожая на ИИН, блокируют запуск.
Это минимальная страховка, а не юридически достаточное обезличивание. В штатный
оценочный корпус разрешено включать только синтетические или отдельно
обезличенные данные. Сырые материалы tenant и production-экспорт использовать
нельзя.

## Архитектура

Публичный seam:

```python
report = evaluate_generation(artifact, evaluator=evaluator, rubric=DEFAULT_RUBRIC)
```

Состав:

- `artifact.py` нормализует замороженный JSON курса;
- `privacy.py` останавливает очевидную передачу PII до сети;
- `rubric.py` хранит версионированные атомарные вопросы;
- `adapters.py` изолирует HTTP TypeSafe и replay-кэш;
- `policy.py` рассчитывает `pass/review/reject` обычным кодом;
- `report.py` создаёт JSON для сравнений и Markdown для человека;
- `cli.py` предоставляет явные replay/live-режимы.

TypeSafe оценивает только отдельные семантические признаки. Он не считает
количество объектов, не вычисляет итоговый балл, не исправляет и не публикует
курс. Текущие пороги имеют режим `report_only`: это исследовательские сигналы,
которые надо откалибровать на принятом синтетическом корпусе до использования в
release gate.

## Запуск

По умолчанию сеть запрещена. Команда читает только ранее сохранённый кэш и
завершается ошибкой при cache miss:

```powershell
python -m scripts.dev.course_quality_eval.cli `
  path\to\course-artifact.json `
  --cache-dir path\to\private-cache `
  --output-dir path\to\report
```

Первичный живой прогон требует явного `--live`. Ключ читается process-locally и
не записывается в отчёт или кэш:

```powershell
python -m scripts.dev.course_quality_eval.cli `
  path\to\synthetic-course-artifact.json `
  --live `
  --env-file "C:\Kamilya New\.env" `
  --cache-dir path\to\private-cache `
  --output-dir path\to\report
```

`--refresh` допустим только вместе с `--live`. Для воспроизводимого сравнения
версий генератора предпочтителен replay одного и того же ответа модели, а новый
live-вызов нужен для изменения рубрики, модели или входного артефакта.

## Рубрика v1

Урок оценивается по поддержке утверждений источником, соответствию целям,
связности, доле механического повторения и практической ценности. Вопрос
оценивается по поддержке правильного ответа, наличию ровно одного правильного
варианта, различимости и правдоподобию дистракторов, атомарности, качеству
пояснения и учебной ценности.

Jev вызывается как закреплённая модель `jev-1.13.0`. Каждая характеристика —
отдельный Noul или Score. Итог формируется детерминированно в `policy.py`, поэтому
один противоречивый общий вердикт модели не может переопределить атомарные
сигналы.

## Приёмка изменения генератора

1. Зафиксировать baseline-артефакт и его SHA-256.
2. Прогнать baseline с закреплённой рубрикой и моделью.
3. Сгенерировать кандидат тем же синтетическим источником и настройками.
4. Сравнить JSON-отчёты по каждому уроку и вопросу.
5. Просмотреть все `reject` и `review` вручную; не оптимизировать только средний
   балл.
6. Добавить подтверждённый дефект в синтетический regression corpus.
7. Выполнить обычные детерминированные тесты production pipeline. TypeSafe-отчёт
   их не заменяет.
8. Только после этого проводить отдельную DEV/production-приёмку неизменённого
   кандидата по `AI-COURSE-01`.

Результаты предназначены для внутренней разработки. Их нельзя публиковать как
сравнительный benchmark TypeSafe/Jev или использовать для обучения/дистилляции
модели.
