# Release Notes — 0.11.78

**Product version:** 0.11.78

**Git tag:** `v0.11.78`

The course catalog offers separate actions for creating a course from documents,
creating one manually, and viewing existing generation jobs. The document picker
supports search and keeps the current selection visible.

If a source review is required, the next action is shown before generation.
The review screen explains known failures and offers a retry. For a composite
PDF, the methodologist can select an inclusive page range. The original file
stays in the library and the approved working edition supplies the course source.

Includes the frontend, API and document worker changes. No database migration.
