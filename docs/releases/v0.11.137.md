# Release Notes — 0.11.137

**Product version:** 0.11.137

**Git tag:** `v0.11.137`

В визуальном редакторе урока доступны блоки «Подсказка» и «Пример». Методист задаёт заголовок и содержание, выбирает место блока и проверяет его в предпросмотре. В опубликованном уроке сотрудник раскрывает каждый блок по заголовку.

Фронтенд совместим с действующим API 0.11.136 и схемой 0192. Предыдущая сборка фронтенда 0.11.136 служит точкой отката.
