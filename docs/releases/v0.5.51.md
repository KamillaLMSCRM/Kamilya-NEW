# Release Notes — 0.5.51

**Product version:** 0.5.51

**Git tag:** `v0.5.51`

**Date:** 2026-09-15

## Для клиентов

- Финальная проверка применяется к фактически используемому движку генерации
  больших Excel- и других структурированных источников.
- Если неверный вариант по смыслу отвечает на вопрос так же, как правильный,
  вопрос удаляется. Новый вопрос только ради количества не добавляется.
- Разговорные и неуместные рекламные сравнения не попадают в готовый учебный
  текст; при временной недоступности модели source-only черновик сохраняет факты
  в нейтральной формулировке.
- Урок может остаться без теста, когда источник не позволяет построить хотя бы
  один однозначный вопрос. Это безопаснее искусственного заполнения.

## Надёжность

- V2 выполняет проверку и во время ответа модели, и повторно над всем итоговым
  курсом непосредственно перед сохранением.
- Качество V2 имеет отдельную версию политики, чтобы идентификатор движка больше
  не использовался вместо версии правил проверки.
- Изменение серверное. Миграции БД и развёртывание frontend не требуются;
  `apps/web/package.json` синхронизирован только из-за действующего общего
  контракта версии монорепозитория.

## Проверка кандидата

- Production-примеры сначала воспроизведены как падающие тесты активного V2.
- Связанные проверки V2, уроков и тестов: 245 — PASS; полный unit-набор API:
  1757 — PASS.
- Полный исходный Excel: 12 уроков, 17 retained-вопросов, `publishable=true`.
- Независимый скан результата: запрещённые фразы, общие вопросы и точные дубли
  отсутствуют.
- Время финального локального production-shaped прогона: 117.688 секунды;
  embeddings — 2.216 секунды через Voyage без деградации.

## Откат

- Откат возвращает единый backend image версии 0.5.50 для API и трёх workers.
- База данных и frontend при откате не изменяются.
