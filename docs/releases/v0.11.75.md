# Release Notes — 0.11.75

**Product version:** 0.11.75

**Git tag:** `v0.11.75`

The methodologist workspace has five primary sections: tasks, courses,
employees, assignments, and the training log. Use the list to select a
record and see its details and related actions on the same page.

In Employees, switch between the roster and the organization tree. Open a
branch to see its direct staff and the staff in its nested units. Use
**Add organizational unit** to choose a unit type and its parent, or use
**Add here** to start with the current unit as the parent.

This release uses the current staff, courses, assignments and reporting
APIs. It requires no database migration.
