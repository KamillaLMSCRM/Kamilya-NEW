# Release Notes — 0.5.14

**Release date:** 2026-09-13
**Product version:** 0.5.14
**Git tag:** `v0.5.14`

## Для клиентов

- В автоматически созданных тестах правильный ответ больше не находится в одной
  и той же позиции во всех вопросах.
- При повторной попытке варианты ответа показываются в другом порядке, поэтому
  запоминание позиции не заменяет знание материала.
- Генерация отбрасывает вопросы без понятного предмета сравнения, выдуманные
  названия в неверных вариантах и механические варианты, отличающиеся одним словом.
- Названия разделов курса по большой таблице отражают реальные темы источника,
  а не технические номера разделов.

## Технические изменения

- Балансировка выполняется при сохранении вариантов и не меняет идентификаторы,
  по которым сервер проверяет ответы.
- Повторная попытка меняет только отображаемый порядок MCQ; вопросы других типов
  сохраняют исходный порядок.
- Автоматическая приёмка проверяет стратегии «всегда выбирать одну позицию» и
  «выбирать самый длинный вариант», контекст вопросов и названия модулей.

## Развёртывание

- Миграции базы данных: не требуются.
- Новые переменные окружения: не требуются.
- Порядок: API и все AI/документные/операционные воркеры, затем нативный
  frontend на CT137.

## Приёмка выпуска

- API unit-профиль: 1443 теста.
- Frontend: 581 тест, typecheck и lint; production build выполняется в release gate.
- Изолированный DEV-контур, exact-SHA CI и полный production-путь с исходным
  Excel выполняются перед окончательной приёмкой.

## Откат

Предыдущий выпуск — `v0.5.13`. API и воркеры возвращаются на его immutable image,
frontend — на сохранённый нативный release CT137. Изменений схемы и данных нет.
