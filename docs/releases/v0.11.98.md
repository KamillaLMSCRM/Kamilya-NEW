# Release Notes — 0.11.98

**Product version:** 0.11.98
**Git tag:** `v0.11.98`

Fresh courses use a frozen V7 path: semantic source-unit plan, independent reading of source actors/actions/conditions before the draft, practical unit authors, then separate addressed teaching and question editors. The reading is fallible assistance: the approved source and recorded decisions govern. Correct similar cards are retained; exact identities, original images, addressed-delta custody, saved responses and earlier-job policies are preserved. Existing V6 response recovery remains narrow and source/request/route bound.

The VM development worker isolates optional private SSH availability from its independently reachable cloud-generation client. Known network failures have three bounded recovery sessions (at most six pinned SSH launches); unknown or remote authentication/host-pin failures quarantine the private bridge without accepting another host or changing providers. Local credentials, bind conflicts and foreign listeners remain guarded. Cloud consumer continuity does not certify OCR or embedding availability. Strict Render/API and disabled-supervisor behavior remain unchanged.

This is a no-migration backend release on schema 0187. Course publication still approves an exact reviewed revision. Real unresolved source ambiguities remain visible; provenance and technical checks are not semantic approval. Customer courses, assignments and history, provider plans, routing, reasoning, production frontend, voice and reserve configuration are retained. Exact DEV, provider and production acceptance evidence belongs to the release receipts and test ledger.
