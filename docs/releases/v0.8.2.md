# Release Notes — 0.8.2

**Release date:** 2026-09-21
**Product version:** 0.8.2
**Git tag:** `v0.8.2`

## Summary

This patch completes direct English entry into the public demo workspace. The
demo-role page now applies the requested language itself and preserves that
language when a visitor returns to sign-in or starts tenant registration.

## Fixed

- Apply `?lang=en` and other supported locale parameters on direct demo-role
  page entry.
- Preserve the selected language on both demo-role page exit links.
- Add regression coverage for direct entry and localized link continuity.

## Security and deployment

- Database migrations: not required.
- Environment variables: no new variables.
- No secret, billing, DNS, storage or tenant-isolation changes.
