# Release Notes — 0.11.81

**Product version:** 0.11.81

**Git tag:** `v0.11.81`

A completed independent source-review reply that fails schema validation gets
one corrective request for the entire analysis run. The request contains the
same original and proposal with safe field-path and validation-type feedback.
The resulting reply must pass the same strict schema and source checks.

Timeouts, unknown transport outcomes and proposal-identity changes keep their
existing failure behavior. Source text and valid findings remain authoritative.
The extra call is included in the stored model-call count.

Backend-only release with no database migration or frontend runtime changes.
