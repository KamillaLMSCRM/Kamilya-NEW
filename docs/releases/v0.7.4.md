# Release Notes — 0.7.4

**Product version:** 0.7.4

**Git tag:** `v0.7.4`

**Date:** 2026-09-19

## Для клиентов

Этот patch-релиз включает улучшения качества генерации из `0.7.3` и исправляет
только метаданные двух внутренних проверочных скриптов. Поведение генератора,
API, worker и интерфейса относительно кандидата `0.7.3` не менялось.

- Вопросы и варианты ответа формируются внутри одного смыслового блока и одной
  проверяемой характеристики источника.
- Невалидные, неоднозначные и повторяющиеся вопросы удаляются без заполнения
  формальной квоты.
- Курс остаётся доступным черновиком, если безопасный тест сформировать не
  удалось; интерфейс ведёт методиста к сохранённому черновику.

## Проверка релиза

- До patch-исправления финальное дерево прошло `2028` API unit tests,
  `619` frontend tests, TypeScript, ESLint, production build, Python quality,
  `AI-COURSE-01` и release contracts.
- GitHub CI `35431736647` остановил `0.7.3` до deployment из-за отсутствующего
  executable mode у двух новых `.sh` файлов. Секреты, frontend, dependency audit
  и завершившиеся функциональные jobs прошли.
- В `0.7.4` оба скрипта имеют Git mode `100755`; полный shell-policy gate
  является обязательной повторной проверкой точного SHA.

## Развёртывание и откат

- Миграция и изменение данных не требуются.
- Синхронно обновляются API, три worker и native frontend exact-SHA артефакт.
- Откат выполняется на production release `0.7.2`; версия `0.7.3` не была
  развёрнута в production.
