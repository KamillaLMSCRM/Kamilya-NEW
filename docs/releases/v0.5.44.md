# Release Notes — 0.5.44

**Product version:** 0.5.44

**Git tag:** `v0.5.44`

**Date:** 2026-09-14

**Статус:** локальный кандидат прошёл полный API unit-suite, обязательные
проверки цепочки «документ → курс → тест» и содержательное воспроизведение
контрольного Excel-файла. CI, DEV и production-приёмка фиксируются отдельно.

## Для клиентов

- В каталогах с артикулами характеристики больше не должны переноситься между
  соседними строками: артикул, коллекция и числовые свойства проверяются вместе.
- Если разные поля источника противоречат друг другу для одной позиции, курс не
  выбирает значение молча. В черновике указывается расхождение и необходимость
  сверки с оригиналом.
- Числовые вопросы дополнительно проверяются по периоду, единицам, базе расчёта
  и условиям. Если формулировка допускает несколько правильных ответов, вопрос
  удаляется.
- Количество вопросов является верхней границей, а не обязательной нормой.
  Система сохраняет только различимые и подтверждённые источником вопросы и не
  создаёт замену ради количества.
- Охват тестами проверяется по всему курсу. Отдельно показываются учебные цели,
  которые не раскрыты в тексте уроков или не проверяются итоговыми вопросами.

## Проверка

- 1672 API unit-теста — PASS.
- 6 database-free проверок `AI-COURSE-01` — PASS.
- Python quality baseline — PASS (`ruff=1065`, `mypy=2333`).
- Полная локальная регенерация контрольного Excel: 4 урока; 73.992 секунды на
  написание, проверку и первичную генерацию тестов. Итоговый source-wide аудит
  сохранил 10 из 11 вопросов и удалил один смысловой дубль без восполнения.
- Сохранённый реальный дефект с неверной коллекцией и количеством дверей теперь
  отклоняется кодами `source_identity_conflict` и `unsupported_numeric_fact`.

## Ограничения и откат

Сгенерированный курс остаётся черновиком и требует проверки методистом перед
публикацией. В выпуске нет миграций, изменений DNS, инфраструктуры, модельных
маршрутов или клиентских данных. Откат возвращает API и workers на неизменяемый
артефакт 0.5.43; frontend-функциональность в этом выпуске не изменяется.
