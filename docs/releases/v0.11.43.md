## Source-bound learner presentation

Plain-text nominal headings are retained as section subjects, not concatenated
into operational instructions. Corroborated authoring/QA metadata is retained
for traceability but not admitted as training facts. Verified writer restoration
uses source-owned subjects. Learner answer explanations state the source-backed
action or value, without document/position/internal testing language.

Immutable assessment keys, operational values, roles, conditions and source
locators are unchanged. Single-word commands and nominal nouns remain distinct.
Complete categorical infinitive-action prohibitions ending in «запрещено» use
a source-owned admissibility question and exact binary opposite instead of a
provider question asking for a positive action. Negated, mixed and quoted rules
are not blindly inverted. Numbers inside a prohibition do not change learner
guidance into a numeric-value label.
No automatic publication, assignments, invitations or historical course repair.

## Release boundary and gates

No migration from 0178; no voice, antivirus activation, landing, DNS, credentials,
resource, provider/model, billing or pricing changes. API and three workers must
match the exact image/SHA. Existing native frontend compatibility is checked
without rebuilding unchanged UI. Existing current/rollback identities are retained.

Required: full API regressions and exact CI, one real DEV generation with
independent source-first semantic review and cleanup, protected backend rollout,
fresh runtime readback, then bounded real learner/browser acceptance and cleanup.
Offline repair acceptance is not a fresh generator or runtime verdict.
