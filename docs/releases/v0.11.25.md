# Release Notes — 0.11.25

**Product version:** 0.11.25
**Git tag:** `v0.11.25`
**Date:** 2026-10-01

На узком экране содержание нативного курса располагается над уроком, а не
занимает большую часть его ширины. Текст урока получает доступную ширину без
горизонтального переполнения; desktop сохраняет боковую навигацию.

Также устранена гонка первого сохранения AI-настроек: готовая форма больше не
теряет нажатие до выполнения lifecycle effect. При замене токена старый запрос
отменяется, его ответ не публикуется, новая форма не остаётся заблокированной.
Ключи и сохранённые значения не меняются этим исправлением; AI-запросы не запускаются.

Персональная ограниченная сессия, восстановление после перезагрузки,
попытки тестов, прогресс, сроки и история назначений не меняются.
Миграций нет; схема0168, billing, DNS, письма и AI-генерация вне изменения.
Точный production SHA и живая приёмка фиксируются в PRODUCTION_READINESS.md.
Откат на0.11.24 возвращает прежнюю раскладку, не меняя учебные результаты.

Production принят на3d1276443ad8735a5c0bf3dd029be5768c46ca6a: мобильный
плеер390px без горизонтального переполнения, desktop сохранён; полное
синтетическое прохождение5уроков/5тестов, результат100%, reload/PDF/сертификат
сохранены. Независимый Test Runner:747/747 и финальная API приёмка PASS.
Фактический rollback0.11.24 сохранён; согласованная очистка локальных API образов
снизила заполнение диска с90% до57%, watchdog success/exit0/timeractive.
OTP/подписанный скан, доставка писем, AI jobs и новый restore drill сюда не входят.
