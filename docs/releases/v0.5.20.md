# Release Notes — 0.5.20

**Product version:** 0.5.20
**Git tag:** `v0.5.20`
**Date:** 2026-09-13

## Для клиентов

- Если две строки большого Excel описывают один и тот же полезный факт разными
  словами, Kamilya сохраняет первый обоснованный вопрос и удаляет повтор.
- Удалённый повтор не заменяется новым вопросом только ради достижения
  запланированного количества.
- Количество вопросов и уроков остаётся верхней границей: небольшой источник
  даёт более короткий курс, а большой источник — только столько самостоятельных
  тем, сколько подтверждено материалом.

## Технические изменения

- Для структурированных источников добавлена консервативная проверка общей
  содержательной фразы в правильных ответах из разных строк.
- Проверка ограничена структурированными источниками и не объединяет одинаковый
  ответ, относящийся к разным предметам или процессам.
- Найденный парафраз относится к drop-only причинам: дополнительный запрос к
  модели для заполнения квоты не выполняется.
- Схема БД, пользовательские данные и интерфейс не изменяются.

## Проверка выпуска

- Реальный production-паттерн зафиксирован отдельным RED-тестом.
- Два отрицательных примера защищают независимые факты от ложного объединения.
- Связанный assessment-набор: 120 PASS; полный API unit-набор: 1482 PASS.
- Полный API unit-набор, version gate, exact-SHA CI, production deployment и
  повторная генерация полного Excel являются обязательными gate выпуска.

## Откат

API откатывается на неизменяемый backend-артефакт `0.5.19`. Изменений БД и
frontend-кода в выпуске нет.
