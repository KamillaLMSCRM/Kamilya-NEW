# Release Notes — 0.5.29

**Product version:** 0.5.29

**Git tag:** `v0.5.29`

**Date:** 2026-09-13

## Для клиентов

- После выбора большого готового документа кнопка генерации больше не ждёт
  повторного OCR или преобразования файла.
- Создание курса быстро ставится в очередь, а длительная проверка и обработка
  источника выполняются внутри видимой фоновой задачи.
- Качество и проверяемость не ослаблены: перед составлением курса система всё
  равно проверяет контрольную сумму оригинала, преобразует его и строит паспорт
  содержания.

## Технические изменения

- Предварительная совместимость и admission используют tenant-owned metadata и
  сохранённое число чанков, не вызывая Docling или LibreOffice.
- Полная direct-source обработка осталась в worker pipeline и выполняется один
  раз на генерацию.
- Схема БД и данные организаций не изменяются.

## Проверка выпуска

- Регрессии требуют, чтобы compatibility и generate-course вызывали облегчённый
  direct-source admission.
- Отдельный тест запрещает вызов конвертера оригинала в облегчённом режиме и
  сохраняет полный тест исходной обработки для фонового worker.
- Финальная production-приёмка выполняется через обычный кабинет методиста на
  реальных PDF и DOC документах ломбарда с фиксацией времени стадий.

## Откат

API и frontend откатываются на неизменяемые артефакты версии `0.5.28`.
Изменений БД для отката нет.
