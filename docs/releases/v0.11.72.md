# Release Notes — 0.11.72

**Product version:** 0.11.72
**Git tag:** `v0.11.72`

New courses use coherent source-backed authoring, editorial review, one scoped
revision when needed, and an independent answer check. The methodologist receives
an editable draft with source references and outstanding findings. Approval stays
bound to the reviewed course revision.

The workspace update brings the full visual design and the Narrow A course
editing improvements together with source review. The navigation adapts to narrow
screens, and the editor protects unsaved work when switching modules or lessons.

New editorial jobs retain the identity of completed model requests after the
database reorders JSON fields. Jobs admitted with earlier policies continue to
use their original request format.

The backend requires database revision 0184. It adds the nullable
`questions.source_quote` column. An application rollback retains that column and
the quotations already saved.
