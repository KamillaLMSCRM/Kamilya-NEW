# Release Notes — 0.5.30

**Product version:** 0.5.30

**Git tag:** `v0.5.30`

**Date:** 2026-09-14

## Для клиентов

- Курсы по нормативным и должностным документам больше не должны прерываться
  только из-за того, что модель повторила утверждённое название урока в виде
  Markdown-заголовка.
- Текст каждого урока по-прежнему обязан содержать проверяемые факты из
  выбранного источника; пустые, шаблонные и неподтверждённые материалы не
  сохраняются.
- Исправление не увеличивает искусственно число уроков и не ослабляет контроль
  качества вопросов.

## Технические изменения

- Из quality admission исключается только H1–H6, дословно совпадающий после
  нормализации с уже проверенным названием урока.
- Этот заголовок больше не засчитывается как источник фактических опор,
  содержательная длина урока или повтор между уроками.
- Любой другой заголовок остаётся частью проверяемого текста, включая
  причинные, обязательные и рекомендательные формулировки.
- Схема БД и данные организаций не изменяются.

## Проверка выпуска

- RED-регрессия воспроизводит отказ на заголовке «Документы, требуемые для
  получения микрокредита» при полностью подтверждённом теле урока.
- Защитная регрессия продолжает отклонять отдельный выдуманный причинный
  заголовок.
- После CI и exact-SHA deployment выполняются продолжение сохранённой
  production-задачи и отдельная полная генерация по должностной инструкции.

## Откат

API и frontend откатываются на неизменяемые артефакты версии `0.5.29`.
Изменений БД для отката нет.
