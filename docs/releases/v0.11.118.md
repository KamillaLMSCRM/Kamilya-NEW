# v0.11.118 — повторные цитаты в проверке исходника

Релиз исправляет привязку доказательств к исходнику и согласование правок.
Одинаковые цитаты одной строки сохраняются все; одинаковый текст разных товаров
не объединяет решения. Замены ограничены исходной строкой, требуют явного выбора
всех совпадений, проверяют редакцию и отражаются в журнале с полной отменой.
Готовые авторские и проверяющие ответы используются повторно. Только замечания
без подтверждённого источника направляются на адресное продолжение существующей
проверки; неизвестный исход запроса не повторяется.

Изменения генерации каталожных курсов ENG-074, большого лимита транспортного
входа и Codex-runner117 исключены. Генератор по умолчанию сохраняет поведение116;
расширенное чтение таблиц используется только проверкой источника. Миграций нет.
Клиентские документы, курсы и результаты сотрудников не меняются.
