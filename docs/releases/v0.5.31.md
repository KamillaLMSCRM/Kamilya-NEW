# Release Notes — 0.5.31

**Product version:** 0.5.31

**Git tag:** `v0.5.31`

**Date:** 2026-09-14

## Для клиентов

- Один слабый урок больше не отменяет весь качественный курс. Если после трёх
  попыток урок не подтверждается исходным документом, он исключается, а
  генерация остальных тем продолжается.
- Система не создаёт замену ради выполнения заданного количества. В итоговый
  курс попадают только уроки, прошедшие проверку по источнику.
- Если качественного материала осталось слишком мало, курс не сохраняется:
  для плана из девяти уроков требуется не менее пяти подтверждённых уроков.

## Технические изменения

- Политика применяется только к детерминированному отказу качества отдельного
  урока после всех ограниченных повторов. Ошибки источника, доступа, лимитов и
  инфраструктуры по-прежнему завершают задание с явной ошибкой.
- Пустые модули не сохраняются. Проверка курса и генерация тестов получают
  фактическое количество принятых уроков, а не первоначальный максимум.
- Схема БД и данные организаций не изменяются.

## Проверка выпуска

- RED-регрессия воспроизводит курс из двух уроков, где второй трижды не проходит
  grounding admission; GREEN сохраняет первый урок и не создаёт замену.
- Существующая регрессия курса из одного непригодного урока продолжает требовать
  полный отказ, подтверждая минимальный порог качества.
- После CI и exact-SHA deployment выполняется полный пользовательский путь по
  PDF правил ломбарда и отдельный путь по должностной инструкции `.doc`.

## Откат

API и frontend откатываются на неизменяемые артефакты версии `0.5.30`.
Изменений БД для отката нет.
