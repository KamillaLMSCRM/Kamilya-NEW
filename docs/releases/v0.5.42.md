# Release Notes — 0.5.42

**Product version:** 0.5.42

**Git tag:** `v0.5.42`

**Date:** 2026-09-14

## Для клиентов

- Объём курса уточняется после чтения исходного материала: вспомогательный
  каталог не должен сам по себе увеличивать число уроков.
- Улучшена обработка сложных Excel-файлов с основными и вспомогательными листами.
- Усилена проверка чисел, условий и вариантов ответов. Повторяющиеся вопросы
  удаляются без искусственного восполнения количества.
- Если часть тем не удалось подготовить, результат явно обозначается как
  неполный черновик с перечнем пропущенных тем.
- Неуверенно распознанные процентные значения в сканах требуют сверки с
  оригиналом; соответствующее предупреждение сохраняется в результате.
- Счётчики прогресса относятся к указанному этапу, а предварительная оценка
  объёма курса не выдаётся за окончательную структуру.

## Проверка и ограничения

Проверены регрессии генерации и тестов, сохранение предупреждений, интерфейс
прогресса и изолированный Supabase DEV-контур. Полный исходный скан прошёл
отдельную проверку конвертера. Это не заменяет проверку содержания готового
курса методистом: автоматическая обработка не гарантирует безошибочность OCR
и сгенерированных учебных материалов.

После выпуска предусмотрено по одному живому прогону полного документа
ломбарда и большого Excel с просмотром каждого урока и вопроса. Результаты
приёмки фиксируются отдельно, а не объявляются успешными заранее.

## Откат

Миграций БД нет. API, workers и frontend могут быть возвращены на неизменяемые
артефакты 0.5.41; для конвертера сохраняется предыдущий образ и конфигурация.
