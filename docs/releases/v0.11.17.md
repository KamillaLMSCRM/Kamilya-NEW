# Release Notes — 0.11.17

**Release date:** 2026-09-29

**Product version:** 0.11.17

**Git tag:** `v0.11.17`

## Changed

- Recurring-learning deadline editing now opens with the saved value and keeps
  second-level precision. An already-open reason history refreshes immediately
  after a successful change.
- Course and program occurrence history retains an employee's name, personnel
  number and active state after that employee leaves the active staff catalog.
- The superadmin tenant heading and impersonation controls wrap cleanly on
  narrow screens.

## Fixed

- A bounded superadmin tenant preview now survives an ordinary full-page reload
  while the original 15-minute token remains valid.
- Leaving tenant preview restores the platform session atomically instead of
  exposing an intermediate anonymous state.

## Security and session boundaries

- The existing impersonation access token is mirrored only in a host-only,
  auth-path, HttpOnly and Secure cookie. It is never written to localStorage or
  sessionStorage and is never reissued to extend its original expiry.
- Restoration requires an active platform-superadmin refresh session plus exact
  actor, target-tenant and allowed-role claim binding. Invalid or expired state
  is cleared and cannot restore tenant access.

## Verification required

- Full API suite, frontend suite, lint, typecheck, Python quality baseline and
  production frontend build.
- Exact-SHA CI and no-migration DEV deployment/readback.
- Production API/worker/frontend identity alignment plus a synthetic browser
  journey covering tenant impersonation, full-page reload, deadline editing,
  event-history refresh, inactive employee identity and preview exit.
