# Release Notes — 0.5.52

**Product version:** 0.5.52

**Git tag:** `v0.5.52`

**Date:** 2026-09-15

## Для клиентов

- Уточнена финальная проверка текста уроков: сравнительная рекламная фраза не
  проходит в черновик, даже если между словами «компактный» и «с маркетплейса»
  стоит дополнительное существительное.
- Обычные факты о размещении товара на маркетплейсе не запрещаются и не
  переписываются.

## Причина выпуска

- Во время пост-релизной проверки каждого из 12 уроков курса, созданного из
  полного Excel, в одном уроке обнаружена грамматическая форма, не покрытая
  политикой версии 0.5.51.
- Курс оставался черновиком; согласование и публикация не выполнялись.

## Проверка кандидата

- Точная production-фраза сначала воспроизведена падающим тестом.
- Проверена как блокировка модельного текста, так и нейтрализация source-only
  fallback с сохранением соседних подтверждённых фактов.
- Повтор полного production-shaped прогона исходного Excel: 12 уроков,
  17 вопросов, `publishable=true`, 114.582 секунды. Voyage обработал 60/60
  embeddings без деградации; независимый текстовый скан не нашёл запрещённую
  формулировку, общий вопрос или её marketplace-варианты.
- Генеративные резервные узлы в этом прогоне отвечали нестабильно, поэтому четыре
  урока сохранены через детерминированный source-only fallback и требуют обычной
  проверки методистом; это отражено честным статусом `degraded_needs_review`.
- Изменение только серверное; миграции БД и развёртывание frontend не требуются.

## Откат

- Откат возвращает единый backend image версии 0.5.51 для API и workers.
- База данных и frontend при откате не изменяются.
