# Release Notes — 0.11.1

**Release date:** 2026-09-24

**Product version:** 0.11.1

**Git tag:** `v0.11.1`

## Для клиентов

Главная страница кабинета методиста стала рабочим обзором обучения. Она
показывает текущее состояние назначений, приоритетные действия и незавершённую
работу с курсами, а не только общие декоративные показатели.

Поддерживаемые показатели и конкретные приоритетные назначения открывают журнал
обучения сразу с нужным фильтром. После просмотра можно безопасно вернуться на
главную страницу; выбранный фильтр сохраняется в адресе и после обновления.

Заголовки разделов бокового меню стали заметнее, а вложенные пункты визуально
отделены. Верхняя панель кабинета корректно помещается на планшетных и узких
экранах.

## Техническая граница

- Миграция базы данных не требуется.
- Новые переменные окружения, тарифы и платные ресурсы не требуются.
- Обновляются frontend, API и три worker-контейнера единым exact-SHA выпуском.
- API добавляет только точный tenant-scoped фильтр журнала по существующему
  `enrollment_id`; неподдерживаемые агрегаты остаются информационными.
- Предыдущий immutable release `v0.11.0` остаётся rollback target.

## Проверка до выпуска

- GitHub CI: 7 из 7 обязательных заданий PASS на функциональном кандидате.
- Frontend: 127 файлов / 696 тестов PASS; typecheck, lint и production build
  PASS; 42 сфокусированных теста навигации PASS.
- API: 3 контрактных теста фильтра PASS.
- Python quality baseline: Ruff 1050 / mypy 2221 без расширения допусков.
- DEV: exact-SHA frontend и API подтверждены; синтетический методистский
  сценарий, URL-восстановление и адаптивность 1440/1024/390 PASS.

После технического изменения версии обязательные version/CI-гейты запускаются
повторно на окончательном release SHA.

## Rollback

При неуспешном runtime readback вернуть CT137 frontend и VM126 API/worker на
сохранённые точные предыдущие releases. Схема CT125 в этом выпуске не меняется.
