# Release Notes — 0.11.125

**Product version:** 0.11.125

**Git tag:** `v0.11.125`

Russian and Kazakh are selected by default for native generation. A course has
one learning and assessment structure. A methodologist reviews the translation
bound to that structure and source before it is available to learners. The
language selector preserves enrollment, progress, quiz history and certificate
identity. Assignment email has one link and text in both languages.

Additive migration 0190 creates the tenant-scoped language edition table with
forced row-level security. Earlier course releases and result rows are kept
intact. The older runtime can run while the new table exists. No destructive
schema downgrade is required for runtime rollback.

This candidate is for DEV validation. Source signing, deployment and acceptance
are recorded by exact revision and environment.
