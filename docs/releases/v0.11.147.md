# Release Notes — 0.11.147

**Product version:** 0.11.147

**Git tag:** `v0.11.147`

В кабинете методиста уточнены названия и действия, обновлены типографика, иконки и поля. В каталоге главным действием остаётся «Создать из документов». Ручное создание, проверки знаний и история генерации доступны через «Ещё». Там же в разделе «Сотрудники» доступны импорт и приглашения.

В назначениях выделено действие подтверждения. В журнале дополнительные фильтры собраны в раскрывающемся блоке, а имя сотрудника остаётся видно при прокрутке таблицы. Рабочее место методиста разделено на два сценария с сохранением введённых данных при переключении.

Обновляется веб-интерфейс. Выпуск совместим с API 0.11.145 и схемой 0192. Миграция не требуется.
