# Release Notes — 0.11.113

**Product version:** 0.11.113
**Git tag:** `v0.11.113`

Methodologists compose lessons as visible Markdown-backed blocks: text, headings,
existing source illustrations with captions, key rules and ordered process steps.
They can move blocks, explicitly confirm deletion and switch to the retained
Markdown editor. Preview and the learner use the same existing LessonContent.
Legacy content remains byte-identical on opening/selecting/switching modes;
unknown Markdown, tables, code, CRLF, source references and source ordinals remain.

No parallel content storage or HTML execution is introduced. Existing lesson PATCH,
unsaved-change/session boundaries and source/review/publication behavior remain
the owners of persistence and approval. New image upload and the remaining
iSpring-inspired assessment/simulation work are separate future packages.

Frontend-only candidate. API/workers remain the accepted 0.11.112 release;
manifest version consistency does not authorize their rollout. No migration,
provider configuration, model inference or customer-course edit is included.
LOCAL / DEV / production acceptance is pending and recorded independently in
the task plan and canonical test ledger; this note is not a deployment receipt.
