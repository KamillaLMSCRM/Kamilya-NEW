# Release Notes — 0.5.6

**Release date:** 2026-09-12
**Product version:** 0.5.6
**Git tag:** `v0.5.6`

## Customer-visible changes

- Long document indexing now shows how many source fragments are complete out
  of the exact total and, after the first completed batch, an estimated time
  remaining.
- Course generation shows exact lesson, review and test counts for the active
  stage in addition to overall progress.
- Large spreadsheet indexing needs fewer managed-provider requests, so fallback
  processing completes sooner without discarding source rows or columns.
- Temporary provider throttling no longer causes the browser to poll
  aggressively or stop watching a valid long-running job after two minutes.

## Safety and compatibility

- Tenant users see progress and time only; internal provider and model names
  remain hidden.
- Existing documents, courses, provider order, tenant limits and authentication
  behavior are unchanged.
- No database migration is required; schema revision remains `0158`.
