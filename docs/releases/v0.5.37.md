# Release Notes — 0.5.37

**Product version:** 0.5.37

**Git tag:** `v0.5.37`

**Date:** 2026-09-14

## Для клиентов

- Создание курса устойчивее к кратковременному разрыву связи с основной
  AI-моделью: отдельная часть анализа документа повторяется автоматически и не
  обрывает весь процесс с общей ошибкой.
- Повторы ограничены по времени и количеству, поэтому интерфейс продолжает
  показывать конечный результат, а не зависает в бесконечной обработке.

## Технические изменения

- `httpx.ConnectError` использует тот же конечный per-provider retry budget,
  который уже применялся для тайм-аутов и временных серверных ошибок.
- Очерёдность DeepSeek → Qwen → GLM и политика автоматического выбора моделей не
  изменены.
- Изменений схемы БД нет; production остаётся на ревизии `0159`.

## Проверка выпуска

- RED/GREEN-регрессия воспроизводит один `ConnectError` и успешный второй вызов
  того же провайдера.
- Профильный failover/source-map gate: 70 тестов успешно.
- После exact-SHA deployment повторяется полный production-путь методиста по
  точной копии документа ломбарда с замерами всех этапов и оценкой курса и тестов.

## Откат

Приложение откатывается на неизменяемые артефакты `0.5.36`. Миграций БД в этом
выпуске нет.
