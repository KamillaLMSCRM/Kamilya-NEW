# Release Notes — 0.11.151

**Product version:** 0.11.151

**Git tag:** `v0.11.151`

- Проверка документа сохраняет замечания при пересечении или неприменимости необязательных правок. Ручные решения и правила применения правок сохраняются.
- Заголовок `X-Request-ID` связывает ответ API с записью по шаблону маршрута. События согласования связывают документ, редакцию, событие очереди и задачу воркера. Записи генерации содержат задание, этап, прогресс и причину приостановки.
- Новые записи используют технические идентификаторы, этапы, коды и счётчики. Тексты источников, запросы и ответы моделей, поля форм и заголовки авторизации в них отсутствуют.
- Схема базы `0194`, режим выпуска `no-migration`. Нативный frontend 0.11.150 совместим с этим выпуском API и воркеров.
