sources. A heading-only first chunk no longer stands in for the substantive opening
body. Ranked candidates are balanced by source before deeper same-source hits.
The model receives an explicit selected-source inventory and clearer distinctions
between supported negative comparison, missing evidence and an actual conflict.
Contextual simplification uses the immediate prior turn rather than an older
topic. Repeated identical questions are re-evaluated without feeding their own
earlier answer back as authority; the saved archive is never rewritten.
Conditions such as “until confirmed” and source-specific appointing authorities
remain distinct. Answer scope excludes unrelated periods and caveats, while an
actual requested-fact conflict retains an explicit qualification when no source
establishes precedence. Requested decision responsibility is not dropped.
The same single inference now declares bounded private requested dimensions
before answering. That declaration is untrusted, validated for shape only and
discarded at the unchanged public boundary; it is not independent fact checking.
For a named conditional scenario the policy retains the complete specific action
set, rather than substitute generic stopping for withdrawal from a hazard.
