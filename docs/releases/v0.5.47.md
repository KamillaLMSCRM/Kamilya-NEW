# Release Notes — 0.5.47

**Product version:** 0.5.47

**Git tag:** `v0.5.47`

**Date:** 2026-09-14

## Для клиентов

- В итоговом просмотре сгенерированного курса текст урока отображается без
  служебных Markdown-маркеров `#`, `**`, обратных кавычек и разделителей таблиц.
- Повторяющийся заголовок урока скрывается в кратком просмотре, а таблицы
  преобразуются в читаемые пары «характеристика — значение».
- В режиме редактирования сохраняется исходный Markdown: изменение касается
  только представления и не переписывает учебный материал.

## Проверка кандидата

- 3 новых frontend-регрессии — PASS.
- TypeScript — PASS.
- ESLint затронутых файлов — PASS.

## Ограничения и откат

Выпуск меняет только нативный frontend. API, workers, схема БД, модельные
маршруты, DNS и лимиты не меняются. Откат возвращает frontend 0.5.46.
