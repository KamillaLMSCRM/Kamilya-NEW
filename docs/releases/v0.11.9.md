# Release Notes — 0.11.9

**Release date:** 2026-09-26

**Product version:** 0.11.9

**Git tag:** `v0.11.9`

## Fixed

- The mandatory-training matrix and summary no longer fail when retained legacy
  data contains more than one independent current enrollment for the same
  employee and course.
- The read model deterministically uses the latest enrollment occurrence while
  preserving every historical enrollment in the training log and evidence
  records.

## Verification

- The production symptom was reproduced on the synthetic tenant as HTTP 500
  from both mandatory-training endpoints and traced to
  `duplicate_current_enrollment`.
- Focused mandatory-training contracts cover order independence, protected
  manual assignments and the production-shaped completed manual/recurring
  duplicate.
- The complete exact-SHA CI, DEV runtime check and production human acceptance
  are release gates for this patch.

## Operations

- Database migration: none.
- Backend deployment is required. The frontend contains only the aligned
  product-version metadata and must be deployed from the same exact SHA.
- No provider plan, billing, DNS or capacity change is required.
