# Release Notes — 0.5.16

**Product version:** 0.5.16
**Git tag:** `v0.5.16`
**Date:** 2026-09-13

## Для клиентов

- При обработке загруженного документа методист видит числовой прогресс индексации:
  процент, количество обработанных фрагментов и ориентировочное оставшееся время.
- Курсы из сравнительных Excel-таблиц сохраняют правильную связь между коллекцией и
  её характеристиками. Вспомогательные листы с номенклатурой не подменяют основную
  структуру обучения.
- Варианты ответов строятся из реальных значений одной характеристики. Если в
  источнике сравниваются три коллекции, система использует три подтверждённых
  варианта и не выдумывает четвёртый.
- Тесты не сохраняют вопрос, если он содержит правильный ответ, повторяет уже
  проверенный факт или спрашивает, как информация представлена в источнике.
- Продолжительность урока учитывает чтение материала и прохождение вопросов.

## Технические изменения

- Добавлена поддержка обеих ориентаций табличных карточек: «коллекция → свойства» и
  «свойство → коллекции».
- Дедупликация выполняется по исходному факту и правильному ответу, не запрещая
  одинаковые слова в разных по смыслу строках.
- Для детерминированного табличного пути убрана пауза внешнего AI-провайдера.
- Интерфейс прекращает опрос завершённых, ошибочных, отменённых и прерванных задач
  индексации и однократно обновляет библиотеку документов.
- Схема БД и пользовательские данные не изменяются.

## Проверка выпуска

- Профильные backend-наборы: 146 PASS по оцениванию, возобновлению и сохранению;
  70 PASS по паспорту документа и прямому источнику; 10 PASS по эксплуатационному
  acceptance gate.
- Профильный frontend-набор: 27 PASS; TypeScript typecheck и lint: PASS.
- Полная локальная регрессия: 1465 backend-тестов и 584 frontend-теста — PASS;
  production-сборка frontend — PASS.
- Граф зависимостей обновлён после проверки безопасного уменьшения: 16 933 узла,
  40 444 ребра, отсутствующие и висячие вершины не обнаружены.
- Сквозная регрессия строит семь уроков по разделённой первичной таблице без вызова
  модели для тестов, без задержки провайдера и только с вариантами из источника.
- До завершения выпуска обязательны exact-SHA CI, DEV-проверка, Release Runner,
  production-readback и полный человеческий прогон исходного Excel.

## Откат

API и frontend откатываются на неизменяемые артефакты `0.5.15`. Миграции БД не
требуются и не откатываются.
