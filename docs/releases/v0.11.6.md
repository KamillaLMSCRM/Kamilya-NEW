# Release Notes — 0.11.6

**Release date:** 2026-09-26

**Product version:** 0.11.6

**Git tag:** `v0.11.6`

## Changed

- Evidence V2 now spends the bounded question budget on distinct source
  entities before adding more characteristics for an already covered entity.
  A three-entity catalog lesson therefore tests all three entities when each
  has an assessable source-owned axis; small documents are still not padded.
- Assessment explanations are deterministic and source-grounded, but now state
  what entity, characteristic or rule is being checked and why the source value
  is the correct one instead of merely echoing the answer.

## Fixed

- The methodologist dashboard localizes generation stages and uses a clear
  fallback title plus a short request reference when a failed job has no course
  title.
- The onboarding completion card now says that workspace setup is complete and
  explicitly leaves current learning and generation problems to the operational
  dashboard below.
- The demo banner uses explicit readable colors in light and dark themes.
