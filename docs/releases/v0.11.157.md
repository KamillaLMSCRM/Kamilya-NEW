# Release Notes — 0.11.157

**Product version:** 0.11.157

**Git tag:** `v0.11.157`

После загрузки файл сразу выбран для курса. Проверку документа можно открыть рядом с выбранным файлом. После генерации переход к проверке черновика виден в начале экрана результата.

Если у сотрудника нет email, форма назначения показывает причину и предлагает выбрать персональную ссылку и PIN. Перед подтверждением видны получатели и способ доступа.

Выпуск веб-интерфейса совместим с действующим API 0.11.154 и схемой 0194.
