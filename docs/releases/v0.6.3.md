# Release Notes — 0.6.3

**Product version:** 0.6.3

**Git tag:** `v0.6.3`

**Date:** 2026-09-17

## Для клиентов

- В форме добавления сотрудника все существующие должности доступны сразу —
  предварительно выбирать отдел больше не требуется.
- Отдел теперь явно необязателен. Сотрудника можно назначить на существующую
  должность без отдела или создать новую должность без отдела.
- Если выбранная должность уже связана с отделом, форма подставляет этот отдел
  автоматически.

## Проверка кандидата

- Компонентные тесты воспроизводят начальное состояние формы, выбор связанной с
  отделом должности и выбор должности без отдела с точным запросом к API.
- Backend-тесты подтверждают, что существующая должность без отдела повторно
  используется, новая создаётся без отдела, а пустая запись отдела не
  материализуется.
- Полный frontend-набор, TypeScript, ESLint и профильные backend-тесты должны
  пройти для точного релизного SHA в CI.

## Безопасность и данные

- Выбранная должность и отдел по-прежнему проверяются внутри текущего tenant;
  cross-tenant идентификаторы не принимаются.
- Реальные клиентские данные в приёмочных тестах не используются.

## Развёртывание

- Миграции базы данных и новые переменные окружения не требуются.
- API, workers и native frontend выпускаются из одного точного SHA.

## Откат

- Приложение можно вернуть на `v0.6.2` без изменения схемы базы данных.
