# Release Notes — 0.11.144

**Product version:** 0.11.144

**Git tag:** `v0.11.144`

Редактор видеоурока проверяет наличие субтитров для выбранного фрагмента. Предлагаемый вопрос и правильный ответ сверяются с субтитрами и между языковыми версиями. Если дорожка недоступна, методист может приложить SRT или VTT.

Схема 0192. Миграция не требуется.
