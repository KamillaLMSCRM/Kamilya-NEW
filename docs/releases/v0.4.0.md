# Release Notes — 0.4.0

**Release date:** 2026-09-10

**Product version:** 0.4.0

**Git tag:** `v0.4.0`

## Собственные ИИ-модели организации

- В настройках администратора организации появился раздел «ИИ-модели».
  Можно отдельно подключить провайдера генерации курсов и тестов и провайдера
  индексации документов.
- Ключи сохраняются в зашифрованном виде и не возвращаются в интерфейс.
  Настройки применяются только к своей организации; подключение можно отключить
  или удалить.

## Создание курса при недоступности индексации

- Курс можно подготовить из проверенного исходного документа, даже если
  семантический индекс пока не готов. Повторно загружать тот же файл не требуется.
- Для больших источников улучшен учёт тем при составлении структуры курса.
  При объединении нескольких источников можно указать общую цель обучения.
- Сообщения об ошибках обработки документов стали понятнее.

## Качество тестов

- Улучшено исправление неудачных вариантов ответов при генерации.
- Исправлено превышение запрошенного количества вопросов при восстановлении
  результата из нескольких попыток.
- Добавлена проверка повторов одного факта с одинаковым правильным ответом.

Сгенерированные материалы остаются редактируемыми черновиками и требуют
проверки ответственного сотрудника перед публикацией.
