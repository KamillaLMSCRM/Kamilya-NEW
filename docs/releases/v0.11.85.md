# Release Notes — 0.11.85

**Product version:** 0.11.85
**Git tag:** `v0.11.85`

This candidate combines the previously DEV-accepted focused v36 engine with the reviewed P1/P2 frontend refinements. Engine generation source is unchanged from 0.11.84. The published 0.11.84 workflow stopped at manifest validation before any production deployment or migration; its immutable tag is preserved.

The release controller now admits exactly the known additive schema0186-to-0187 epoch. Existing earlier version epochs, rollback constraints and runtime-setting history remain protected. The installed controller must be updated through the existing protected upgrade workflow before application rollout.

Contextual menus close consistently with keyboard focus restoration. Course publication details are collapsible while source review, unsaved changes and missing illustrations remain visible. Dashboard data loads independently; retries affect only failed sources and stale session/tenant responses are ignored. Queue counts distinguish visible rows, bounded source totals and unknown totals, including the backend training truncation flag. Mobile catalog/record actions remain accessible.

Independent local verification, exact-SHA DEV/runtime readback, protected production deployment and live synthetic acceptance are recorded separately in the canonical handoff and test ledger. Synthetic browser fixtures prove frontend behavior, not real backend or tenant isolation. Existing customer courses and staff remain outside this smoke-test scope. No provider plan, billable resource, permission, voice or reserve configuration is changed.
