# Release Notes — 0.8.0

**Release date:** 2026-09-21
**Product version:** 0.8.0
**Git tag:** `v0.8.0`

## Summary

Kamilya LMS and its public website now support English alongside Russian and
Kazakh. The release also keeps advertising attribution intact through the
landing-to-trial journey and makes the public learner demo more reliable.

## Added

- English landing pages for the main product, onboarding, candidate assessment,
  finance, product updates, privacy and terms routes.
- English tenant and learner flows for login, registration, invitations,
  navigation, course management, generated-course review, assessments and
  recurring assignments.
- A localized, learner-facing Markdown preview in the wide lesson editor.

## Changed

- Language is preserved in public links and authentication transitions.
- Campaign parameters are carried from landing calls to action into trial and
  demo links.
- Existing staff hierarchy, course-generation and reminder behavior is retained
  while its current user-facing text is localized.

## Fixed

- The learner demo can provision a safe synthetic fallback when the prepared
  learner is unavailable.
- Course generation can continue in direct-source mode when embeddings are not
  available, with a clear compatibility state in the interface.

## Security

- No tenant, authorization, secret, billing, DNS or storage boundary changes.
- Demo fallback data remains synthetic and tenant-scoped.

## Upgrade / deployment notes

- Database migrations: not required.
- Environment variables: no new required variables.
- Production scope: synchronized API/workers plus the separate native cabinet
  and landing services on CT137. Vercel remains a rollback artifact only.
- Rollback: application release `v0.7.7`; landing rollback is the immediately
  preceding immutable CT137 landing release.

## Verification required for acceptance

- Exact candidate CI and immutable artifact verification.
- Production readback for API, all workers and native cabinet.
- Native CT137 landing deployment and exact release-header readback.
- Browser smoke for `/en`, English login/registration and both demo roles.
