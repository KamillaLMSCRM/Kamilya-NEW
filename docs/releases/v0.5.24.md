# Release Notes — 0.5.24

**Product version:** 0.5.24
**Git tag:** `v0.5.24`
**Date:** 2026-09-13

## Для клиентов

- Вопросы по Excel теперь удаляются, если они спрашивают не знание, а то, «как
  сформулировано в источнике».
- Вопрос должен называть конкретную коллекцию или предмет. Формулировки с
  потерянным контекстом вроде «у взрослого размера» или «эта коллекция» не
  попадают в готовый тест.
- Вариант ответа не может быть вопросительным фрагментом или длинным перечислением
  нескольких независимых свойств.
- Удалённые вопросы не заменяются искусственными вопросами ради количества.

## Технические изменения

- Расширены проверяемые признаки source-meta, unscoped attribute, deictic subject,
  interrogative answer и enumerated answer для структурированных источников.
- Исправлено распознавание русских названий в разных падежах; первое слово вопроса
  больше не считается названием только из-за заглавной буквы.
- Схема БД, пользовательские данные и интерфейс не изменяются.

## Проверка выпуска

- Пять production-формулировок из полного файла «Империал_Феникс_Чикаго» добавлены
  как отдельные регрессионные тесты.
- Связанный assessment-набор, полный API unit-набор, version gate, exact-SHA CI,
  production deployment и новая генерация полного Excel являются обязательными
  gate выпуска.

## Откат

API откатывается на неизменяемый backend-артефакт `0.5.23`. Изменений БД и
frontend-кода в выпуске нет.
