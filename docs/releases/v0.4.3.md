# Release Notes — 0.4.3

**Release date:** 2026-09-10

**Product version:** 0.4.3

**Git tag:** `v0.4.3`

## Более строгая проверка ответов в тестах

- При генерации правильный ответ должен быть коротким точным фрагментом
  материала урока. Простого совпадения слов по теме больше недостаточно.
- Проверка отклоняет добавленные свойства и изменённые числовые значения,
  отсутствующие в выбранном фрагменте.
- Объяснение показывает соответствующий текст урока, без дополнительных
  утверждений модели.

Изменение применяется к новой генерации: сохранённые тесты автоматически не
переписываются. Черновики по-прежнему требуют проверки методистом — совпадение
ответа с текстом не гарантирует корректность самого источника или вопроса.
