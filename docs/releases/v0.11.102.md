# Release Notes - 0.11.102

**Product version:** 0.11.102
**Git tag:** `v0.11.102`

Managed connector HTTP rejections retain finite, fully received and credential-safe error codes, HTTP status, byte count, body hash, wire hash and owned stage/route identity. Evidence is persisted under the existing claim and source lock without authorizing an automatic retry. Incomplete, malformed, oversized, credential-bearing or unverified responses remain unknown. Capacity does not imply a zero monetary cost.

The permanent managed-Luna DEV QA contour supports one explicitly acknowledged retry of an unfinished pure-text stage through the existing same-job resume admission. The operation archives the original unknown attempt, preserves its private claim and result records, validates current source pins, and snapshots completed stage identities and result hashes. All completed stages must replay exactly before the failed request may run; changed prompts, source, route, output cap or cache stop before another model request. Only the unfinished stage receives a new recovery checkpoint identity. The operation is unavailable in production and other tenants.

The original DEV101 HTTP503 body cannot be reconstructed and is not reclassified as capacity. Its usage and cost remain unknown. This candidate changes no course-generation roles, prompts, provider plans, reasoning levels or customer data and requires no database migration. Three full Luna DEV courses, final DeepSeek DEV and protected production plus live synthetic acceptance remain separate release gates.
