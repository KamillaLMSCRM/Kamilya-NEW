# Release Notes — 0.11.3

**Release date:** 2026-09-25

**Product version:** 0.11.3

**Git tag:** `v0.11.3`

## Fixed

- The superadmin operations dashboard now waits for the observed production
  Celery control-plane latency before declaring worker roles unavailable.
- The endpoint remains fail-closed: broker failures, missing task registration
  and missing queue topology are still shown as unavailable rather than healthy.

## Verification

- A sanitized VM126 probe received three responses for `ping`, `registered`
  and `active_queues` at the production broker boundary.
- The new delayed multi-worker regression failed with the former 750 ms budget
  and passes with the corrected bounded timeout.
- Exact-SHA CI, DEV browser acceptance and production runtime/browser readback
  are required before this release is accepted.
