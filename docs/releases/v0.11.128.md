# Release Notes — 0.11.128

**Product version:** 0.11.128

**Git tag:** `v0.11.128`

Native lessons support bounded YouTube clips and one optional practice question.
Authors can use the preview's current timestamp, enter it manually, and review
the Russian and Kazakh wording before making the question visible. A draft can
also be proposed from captions when the Luna connector is available.

Learners can skip the exercise during playback or answer it for feedback.
Practice does not create test attempts or change official results.

This release uses the existing course metadata and requires no database migration.
