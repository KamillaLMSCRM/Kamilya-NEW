# Release Notes — 0.11.8

**Release date:** 2026-09-26

**Product version:** 0.11.8

**Git tag:** `v0.11.8`

## Added

- Methodologists can be assigned responsibility for an organization-unit
  subtree or an employee group.
- The mandatory-training matrix explains why each course is required, its
  source rule, current coverage and operational state.

## Changed

- Mandatory-training and training-log rows, summaries and CSV exports respect
  the same responsibility scope. Administrators and methodologists without an
  explicit assignment retain tenant-wide reporting for compatibility.
- The methodologist interface clearly identifies scoped reporting and exposes
  responsibility ownership in organization and group management.

## Fixed

- Employee-group responsibility selectors now load active methodologists rather
  than filtering the list as learners.
- Render Free no longer appears to own DEV migrations. The canonical Supabase
  DEV revision is checked and applied through an explicit fail-closed gate.

## Security

- Employee-group owners must be active methodologists in the same tenant. The
  API and database trigger enforce the invariant, and scoped exports use the
  same policy as on-screen reports.
