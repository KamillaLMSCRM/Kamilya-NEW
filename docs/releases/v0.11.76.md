# Release Notes — 0.11.76

**Product version:** 0.11.76

**Git tag:** `v0.11.76`

The methodologist workspace uses shorter headings and labels in Tasks, Courses,
Employees, Assignments and the Training Log. CSV export includes all records that
match the active filters.

Employee import has its own screen. **Back to employees** restores the roster or
the selected organization unit. This frontend release requires no database
migration.
