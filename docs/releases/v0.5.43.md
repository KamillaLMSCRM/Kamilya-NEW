# Release Notes — 0.5.43

**Product version:** 0.5.43

**Git tag:** `v0.5.43`

**Date:** 2026-09-14

**Статус:** кандидат прошёл локальную содержательную проверку двух контрольных
документов с замечаниями для методиста. Production-приёмка фиксируется отдельно
после exact-SHA развёртывания; рост количества вопросов сам по себе не является
доказательством готовности курса.

## Для клиентов

- Ответы проверяются независимо от ключа генератора по исходным материалам.
  Неоднозначные вопросы и смысловые повторы между уроками удаляются.
- Пропущенные учебные цели получают один проход дополнения без пересоздания
  готовых уроков. Замечания об охвате тем остаются для проверки методистом,
  даже если повторная модельная оценка стала более оптимистичной.
- Если заключительная проверка не завершилась, генерацию можно продолжить
  с сохранённых этапов; непроверенные вопросы не выдаются за готовый результат.
- Некачественные и повторяющиеся вопросы удаляются без искусственного
  восполнения количества и для обычных текстовых документов.
- Если для урока не осталось подходящих вопросов, сам урок сохраняется.
  Черновик содержит предупреждение с названиями уроков, которым нужен тест.
- Исправлен ложный отказ при формулировке цели курса со словами «подбор»
  и «подбирать».
- Для курса с указанной аудиторией или учебной целью составные уроки пишутся
  полностью, а не заменяются сокращённой табличной карточкой.
- Указания по обработке нераспознанных процентов не добавляются к материалам,
  в которых такой проблемы нет.

## Проверка и ограничения

Добавлены локальные запись и повторное воспроизведение запросов и ответов модели.
Они позволяют проверять конкретный этап на том же материале без повторения
всего рабочего процесса в production. Частичный replay и новые ответы модели
учитываются отдельно от полного исторического воспроизведения.

Сгенерированный результат остаётся черновиком для проверки методистом.
Уменьшение количества вопросов не означает полноту проверки знаний, а успешное
завершение генерации не гарантирует отсутствие фактических и методических ошибок.
Текущие результаты живой приёмки фиксируются в `docs/PRODUCTION_READINESS.md`.

## Откат

Миграций и изменений схемы БД нет. API, workers и frontend возвращаются на
проверенные неизменяемые артефакты0.5.42. Docling, маршруты моделей, DNS,
прокси и публичный лендинг в этот выпуск не входят.
