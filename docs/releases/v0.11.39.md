## Source-grounded draft lesson correction

In the draft course editor, describe the desired change to one lesson, inspect
the proposed text against the previous version and original-source references,
then explicitly confirm application. Changing the instruction creates a fresh
server-owned proposal; loading an existing proposal does not invoke AI again.
References show locator/hash metadata, not a source-file opener.

The proposal binds the tenant, active methodologist, lesson/course versions,
source versions and admitted original-document evidence. Missing, stale, foreign
or ambiguous provenance is refused. Preview alone does not edit a lesson. Apply
uses the exact proposal revision/fingerprint, marks source/quiz/course for renewed
review, and leaves the course unpublished. It does not assign learners, alter
completed learning records, publish content or launch another AI request.

Repeated confirmation returns the historical receipt without overwriting later
manual edits. Unknown-result recovery reads the receipt first; requests are never
automatically repeated. Authoritative structured refusals allow a deliberate new
submission; uncertain outcomes retain the same request identity. RU/KK/EN help
explains these states and review duties.
