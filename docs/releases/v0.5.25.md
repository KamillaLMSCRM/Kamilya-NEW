# Release Notes — 0.5.25

**Product version:** 0.5.25
**Git tag:** `v0.5.25`
**Date:** 2026-09-13

## Для клиентов

- При создании курса из Excel система больше не перегенерирует слабые вопросы
  только ради достижения заданного количества.
- Каждый вопрос проходит независимую проверку. Некорректные, повторяющиеся или
  плохо подтверждённые источником вопросы удаляются, а валидные сохраняются.
- Если для урока не осталось полезных проверочных вопросов, курс всё равно
  создаётся: урок сохраняется без теста и доступен методисту для проверки.

## Технические изменения

- Для структурированных источников закрытый перечень отдельных ошибок заменён
  единым правилом фильтрации любого невалидного вопроса после первого успешно
  разобранного ответа модели.
- Повторные обращения к модели сохраняются для ошибок формата ответа, но не для
  искусственного заполнения квоты вопросами.
- Схема БД, пользовательские данные и интерфейс не изменяются.

## Проверка выпуска

- Регрессионный тест воспроизводит прежние пять обращений и отказ, затем
  подтверждает один вызов модели и сохранение только валидного вопроса.
- Полный API unit-набор, assessment/direct-source наборы, release/version gates,
  exact-SHA CI, production deployment и новая генерация полного Excel являются
  обязательными gate выпуска.

## Откат

API откатывается на неизменяемый backend-артефакт `0.5.24`. Изменений БД и
frontend-кода в выпуске нет.
