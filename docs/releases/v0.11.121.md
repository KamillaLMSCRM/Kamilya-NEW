# Release Notes — 0.11.121

**Product version:** 0.11.121

**Git tag:** `v0.11.121`

Learner assistance is bound to one accessible lesson. Chat and history require
its ID and validate both course and tenant ownership. The course-wide fallback
and silent 7000-character clipping are removed. Native player and assistant use
the same complete Lesson.content; the editor assistant and assessment keys are
not part of the learner context. Non-student principals cannot write learner chat.

An optional request may select only the already-enabled Luna reserve; this does
not enable providers or change global ordering and cannot fall back to DeepSeek.
Source, course content, learning results and retained message rows are unchanged.
No schema migration, model/reasoning/provider-plan change or generation-engine
119/120 code is included. Source baseline is accepted production118; DEV, quality
and production acceptance are recorded separately after actual verification.
