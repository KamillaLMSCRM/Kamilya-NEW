# Release Notes — 0.7.5

**Product version:** 0.7.5

**Git tag:** `v0.7.5`

**Date:** 2026-09-19

## Для клиентов

Генератор курсов и тестов точнее сохраняет смысл исходного документа и не
пытается набрать заранее заданное количество вопросов за счёт слабых вариантов.

- Каждый вопрос проверяет один конкретный факт или правило из своего смыслового
  блока источника.
- Неверные варианты должны относиться к тому же практическому вопросу; истинные,
  но посторонние фразы из соседних разделов больше не принимаются как ответы.
- Неоднозначные, повторяющиеся, незавершённые и технические вопросы удаляются без
  искусственной замены.
- Если безопасного теста для части материала недостаточно, курс сохраняется как
  черновик для проверки методистом, а не выдаётся за полностью проверенный.
