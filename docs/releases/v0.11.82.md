# Release Notes — 0.11.82

**Product version:** 0.11.82

**Git tag:** `v0.11.82`

Candidate for source preparation with semantic document parts and embedded
illustrations. A methodologist can adjust the automatically proposed selection;
the existing review, correction journal and immutable approval bind that exact
material. Native DOCX and raster PDF assets retain their source identity.
Static PDF vector/annotation pages use bounded raster rendering; interactive
widgets fail explicitly rather than losing graphics. Image readings receive
pixel-based editorial verification, with durable completed-result recovery.
Other supported document types use their existing recognized text for part planning.

Selected illustrations can appear in the generated lesson. Server validation
binds each image to an approved source. Author access, learner frozen releases
and reviewer frozen attempts have distinct authorization checks. Historical
releases and approval revisions retain source documents and image bytes.

Migration: exact additive 0185 → 0186, extending constraints on the existing
runtime_settings catalog. No business rows or audit history are rewritten.
Old binary rollback is compatible while new catalog overrides have not been set;
otherwise revert the new overrides through the audited settings interface first.
Downgrading schema with new overrides fails and preserves data.

Local tests and isolated DEV schema checks precede hosted DEV acceptance.
This candidate note does not establish deployment or semantic acceptance; exact
runtime and both requested source-to-course results belong to the test ledger.
