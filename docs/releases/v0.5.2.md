# Release Notes — 0.5.2

**Release date:** 2026-09-11
**Product version:** 0.5.2
**Git tag:** `v0.5.2`

## Customer-visible changes

- A signed-in browser tab left open without activity now returns to the login
  screen when the eight-hour session limit is reached.
- Returning to a tab after the computer or browser was suspended immediately
  rechecks the session instead of leaving a stale authenticated screen open.

## Security and compatibility

- Refreshing an access token or selecting another assigned role keeps the
  original login deadline and cannot start a new eight-hour period.
- Already-issued sessions remain compatible and are upgraded to the new
  browser deadline after server revalidation.
- No database migration is required; schema revision remains `0158`.
