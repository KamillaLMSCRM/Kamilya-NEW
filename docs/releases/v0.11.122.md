# Release Notes — 0.11.122

**Product version:** 0.11.122

**Git tag:** `v0.11.122`

authenticated learner, tenant, course and current accessible lesson. The complete
current lesson is included once. Conversation references and examples can guide
follow-ups; current lesson material remains authoritative for factual rules.

with questions preceding same-transaction answers. All older rows remain stored.

schema migration, new runtime setting, provider/reasoning/plan/order/rights change.

source is unchanged. DEV/production Luna and ordinary student UI acceptance must be
recorded separately. No client document/course/test or employee result edits.
