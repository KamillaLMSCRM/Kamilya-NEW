# Release Notes — 0.11.136

**Product version:** 0.11.136

**Git tag:** `v0.11.136`

В визуальном редакторе урока доступна загрузка PNG и JPEG. Методист может добавить подпись, описание изображения и проверить его расположение перед публикацией. Изображение открывается у назначенного сотрудника из опубликованной редакции курса.

При обновлении курса по новой редакции источника иллюстрации и переводы неизменённых частей переходят в новый черновик.

Выпуск использует схему 0192. Для восстановления используются предыдущие API 0.11.133 и фронтенд 0.11.134.
