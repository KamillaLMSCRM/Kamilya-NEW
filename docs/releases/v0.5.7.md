# Release Notes — 0.5.7

**Release date:** 2026-09-12
**Product version:** 0.5.7
**Git tag:** `v0.5.7`

## Customer-visible changes

- Document indexing again uses the established Qwen embedding gateway before
  managed fallback providers.
- Long indexing and course-generation operations show completed units, total
  units and a measured remaining-time estimate in the tenant interface.
- Large spreadsheet indexing uses bounded retries, provider-safe batches and
  long-running browser monitoring instead of silently stopping after two
  minutes.

## Safety and compatibility

- The restored Qwen route was verified from the production documents worker
  with a synthetic 4096-dimensional embedding before this release.
- The tenant interface does not expose internal provider or model names.
- Existing documents and courses remain available. Documents indexed in a
  different embedding space are reindexed before semantic retrieval.
- No database migration is required; schema revision remains `0158`.
