# Release Notes — 0.11.24

**Product version:** 0.11.24
**Git tag:** `v0.11.24`
**Date:** 2026-10-01

Персональный вход сотрудника теперь может сохранить ту же ограниченную сессию
после перезагрузки страницы. Старый вход методолога не подменяет ученика.
Восстанавливается прежний токен с оставшимся сроком, а не новая продлённая сессия.
Отозванный, истёкший или не соответствующий назначению доступ закрывается без
перехода в предыдущую учётную запись. Для обычного входа нужно явно войти заново
или выйти из ограниченного доступа.

Сервер сохраняет все ограничения конкретного назначения: tenant, сотрудник,
credential, сроки, отзыв и отдельные правила чтения результата после завершения.
JWT и PIN не сохраняются в localStorage/sessionStorage. Cookie использует
существующий защищённый browser profile; персональный вход согласован с общей
блокировкой refresh, чтобы конкурентное восстановление не отменило вход ученика.

Миграций нет, схема0168 не меняется. Billing, DNS, клиентские данные, письма,
AI-генерация и другие проекты вне выпуска. Синтетические результаты не сбрасываются.
API, три workers и CT137 frontend выпускаются на одном точном SHA существующими
контроллерами после локальных, CI, DEV и rollback gates. Production acceptance
принадлежит отдельному Test Runner; недоступность его browser executor не скрывается.
Фактические deployment/readback и границы приёмки фиксируются в
`docs/PRODUCTION_READINESS.md`, не выводятся из этой заметки.

Контракт: `docs/product/contract-modules/assignment-session/SESSION_V1.md`.
Откат на0.11.23 возвращает memory-only персональную сессию; enrollment history
и бизнес-сроки не изменяются. Предыдущие immutable runtime artifacts сохраняются.
