# Release Notes — 0.11.100

**Product version:** 0.11.100
**Git tag:** `v0.11.100`

New courses use semantic source units and their literal dependencies. After each unit is authored, the reviewer compares its actual teaching with the approved source. An independent whole-course review checks the lesson bodies, followed by one coordinated editor for lesson and question corrections. Earlier model interpretations are not supplied as source authority.

The editor applies physical block and question addresses, preserving unedited material and source illustrations. A conflicting block address can receive one explicit address-only reconciliation that cannot rewrite prepared content. Known unapplied corrections preserve the original draft and visible findings; unknown provider outcomes are not silently repeated.

Material reviewer findings retain individual dispositions bound to the original source, draft and actual final course. Evidence-backed model claims remain attributed to the model and do not constitute semantic or human approval. Missing or unsupported decisions remain visible. Citation typography can use the existing reversible literal normalization; abbreviated or altered quotations are not treated as verified evidence.

This candidate has no database migration and retains schema 0187, provider plans, reasoning, customer data, historical generation policies and rollback. Saved-response controls and local tests do not establish deployment or fresh-course acceptance. Three full Luna DEV courses, final DeepSeek DEV acceptance and protected production deployment with a live synthetic lifecycle remain separate required gates.
