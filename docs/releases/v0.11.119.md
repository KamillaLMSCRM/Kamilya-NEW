# Release Notes — 0.11.119

**Product version:** 0.11.119

**Git tag:** `v0.11.119`

Согласование больших таблиц: поиск по артикулу или замечанию, ограниченная по
высоте очередь и правка конкретного фрагмента подтверждённой строки. Полная
строка вычисляется только из канонической позиции и буквального доказательства;
чужие, устаревшие и непроверенные цитаты не получают права на изменение.
Сохранённые модельные ответы, автоправки и утверждённые редакции не пересоздаются.

Восстановлена подготовленная ENG-074 инструкция планировщику: тематические
уроки используют каталог как источник, без отдельного урока на каждый артикул.
Отправитель и приёмник используют одинаковый предел транспортных байтов8MiB;
модель, reasoning и выходной лимит не меняются. Миграций нет.

LOCAL / DEV / production подтверждаются отдельными фактическими записями.
Согласованные root значения на тестовой копии — учебные допущения для проверки
процесса, не утверждение достоверности характеристик клиентского каталога.
