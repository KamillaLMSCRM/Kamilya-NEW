# Release Notes — 0.11.27

**Product version:** 0.11.27
**Git tag:** `v0.11.27`
**Date:** 2026-10-02

Исправление упаковки совместимого frontend-этапа рабочего места методиста.
Штатный deployment helper и его восьмиполевой manifest не меняются. Параметры
сборки проверяются отдельным build-config.json, связанным с точным SHA исходников,
хешами архива и manifest. Рабочее место явно выключено; неправильные или
изменённые параметры отклоняются до загрузки на сервер.

Предусмотрен frontend-only выпуск поверх совместимого backend0.11.26/schema0169.
Proxmox, расширение прав, миграции, включение функции, голосовые/LLM-запросы,
отправка писем и очистка старых релизов этим пакетом не выполняются.

Статус: кандидат; точный CI/artifact/runtime и приёмка публикуются только после
независимых проверок в docs/PRODUCTION_READINESS.md. Полный запуск функции
остаётся отдельным финальным этапом0170–0172 с совместимым application rollback.
