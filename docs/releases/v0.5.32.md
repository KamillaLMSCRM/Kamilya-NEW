# Release Notes — 0.5.32

**Product version:** 0.5.32

**Git tag:** `v0.5.32`

**Date:** 2026-09-14

## Для клиентов

- Большой фрагмент распознанного PDF больше не должен прерывать генерацию курса
  до появления первого урока только из-за внутреннего лимита контекста модели.
- В модель передаётся дословный фрагмент выбранного документа, помещающийся в
  безопасный лимит. Название документа, раздел и связь с исходным материалом
  сохраняются.
- Исправление не дополняет документ вымышленным текстом, не ослабляет проверку
  качества уроков и не создаёт уроки ради заданного количества.

## Технические изменения

- Для одного документа writer вычисляет доступный объём по полной сериализации
  запроса и, если целый OCR-чанк не помещается, использует его точный префикс с
  границей по абзацу, строке или предложению.
- Запросы по нескольким документам по-прежнему завершаются безопасной ошибкой,
  если каждый источник нельзя представить целым чанком; слишком большие
  заголовки и параметры курса также не обрезаются.
- Release workflow проверяет формат release ID, предыдущего SHA и immutable
  rollback image до запуска сборки production-образа.
- Схема БД и данные организаций не изменяются.

## Проверка выпуска

- RED-регрессия воспроизводит production-ошибку на одном 55,999-символьном
  OCR-чанке до обращения к модели.
- GREEN-регрессия подтверждает ограниченный дословный фрагмент, полный prompt не
  больше 32,000 символов и сохранённую ссылку на исходный документ.
- Защитные тесты продолжают отклонять неподъёмные метаданные и небезопасное
  обрезание одного из нескольких документов.
- После exact-SHA deployment выполняются свежие полные пользовательские пути по
  PDF правил ломбарда и должностной инструкции `.doc` с фиксацией стадий,
  времени, сохранённого курса и качества тестов.

## Откат

API и frontend откатываются на неизменяемые артефакты версии `0.5.31`.
Изменений БД для отката нет.
