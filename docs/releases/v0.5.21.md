# Release Notes — 0.5.21

**Product version:** 0.5.21
**Git tag:** `v0.5.21`
**Date:** 2026-09-13

## Для клиентов

- Повтор вопроса удаляется и тогда, когда один правильный ответ содержит
  дополнительную подтверждённую деталь, но оба ответа проверяют один основной
  факт.
- Kamilya сохраняет первый полезный вопрос и не создаёт замену только ради
  запланированного количества.
- Количество вопросов и уроков является верхней границей, а не квотой.

## Технические изменения

- Уточнён порог консервативного сравнения содержательных фраз в ответах из
  структурированных источников.
- Проверка по всем 18 ответам реального production-курса выделила только
  фактический повтор «на всю квартиру» и не объединила остальные вопросы.
- Схема БД, пользовательские данные и интерфейс не изменяются.

## Проверка выпуска

- Длинная формулировка реального ответа сначала воспроизвела пропуск фильтра в
  RED-тесте и прошла после исправления.
- Два отрицательных примера защищают независимые факты от ложного объединения.
- Связанный assessment-набор: 120 PASS; полный API unit-набор: 1482 PASS.
- Полный API unit-набор, version gate, exact-SHA CI, production deployment и
  повторная генерация полного Excel являются обязательными gate выпуска.

## Откат

API откатывается на неизменяемый backend-артефакт `0.5.20`. Изменений БД и
frontend-кода в выпуске нет.
