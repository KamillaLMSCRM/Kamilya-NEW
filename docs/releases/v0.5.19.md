# Release Notes — 0.5.19

**Product version:** 0.5.19
**Git tag:** `v0.5.19`
**Date:** 2026-09-13

## Для клиентов

- Повторяющий уже проверенный факт вопрос удаляется, даже если во втором уроке
  правильный ответ сформулирован чуть короче или длиннее.
- Вопрос по таблице должен прямо называть коллекцию, товар или иной предмет
  проверки. Формулировки без понятного предмета в тест не сохраняются.
- Слабые варианты ответа, полученные механической заменой одного слова, не
  используются для искусственного увеличения теста.
- Заданное количество вопросов и уроков остаётся верхней границей. Kamilya не
  дополняет курс повторами или выдуманными материалами ради достижения числа.

## Технические изменения

- Смысловое сравнение межурочных ответов допускает короткий описательный префикс
  при сохранении одного и того же содержательного ядра.
- Структурная привязка к ячейке восстанавливается для строк Markdown-таблицы,
  разделённых обработчиком предложений.
- Валидатор структурированных вопросов отклоняет неназванный или неопределённый
  предмет и короткие наборы низкоинформативных дистракторов.
- Отклонённые по этим причинам кандидаты удаляются за один проход без повторного
  запроса к модели и без заполнения квоты.
- Схема БД и пользовательские данные не изменяются.

## Проверка выпуска

- Шесть регрессий воспроизвели новые дефекты production-курса и защиту от
  ложного срабатывания до исправления и прошли после него.
- Смежный assessment-набор: 119 PASS; полный API unit-набор: 1480 PASS.
- Frontend: 584 PASS, lint, typecheck и production build PASS.
- Локальный критический путь `AI-COURSE-01`: 5 PASS; один DB-тест оставлен
  каноническому CI-контуру.
- Exact-SHA CI, защищённый production deploy и повторная браузерная генерация
  полного Excel являются обязательными последующими gate выпуска.

## Откат

API и frontend откатываются на неизменяемые артефакты `0.5.18`. Миграции БД не
требуются и не откатываются.
