# Release Notes — 0.5.8

**Release date:** 2026-09-12
**Product version:** 0.5.8
**Git tag:** v0.5.8

## Customer-visible changes

- Document indexing uses the dedicated Qwen embedding service through the
  private KZ WireGuard route, without a public embedding hostname.
- The existing Voyage and Cohere fallbacks remain available if the private
  embedding service cannot complete a request.
- Existing documents and courses remain available. A document is reindexed
  automatically when its stored embedding space differs from the active one.

## Safety and compatibility

- Model discovery and a real synthetic embedding request were verified from
  VM126 through the private route; the returned vector has 4096 finite values.
- The tenant interface does not expose provider names, model names or network
  addresses.
- No database migration is required; schema revision remains 0158.
