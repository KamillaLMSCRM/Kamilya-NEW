# Release Notes — 0.7.2

**Product version:** 0.7.2

**Git tag:** `v0.7.2`

**Date:** 2026-09-18

## Для клиентов

- Большие нормативные документы формируют последовательные уроки по реальным
  разделам источника; пункты списков больше не превращаются в ложные разделы.
- Большая вспомогательная номенклатура в Excel обогащает курс, но не раздувает
  его до отдельного урока на каждый артикул.
- Количество уроков и вопросов определяется объёмом полезной информации:
  небольшой источник не дополняется искусственно, а большой разбивается на
  редактируемые части.
- Из тестов удаляются вопросы на запоминание артикулов и размеров без учебной
  ценности, подсказки в формулировке, повторы одного факта и пересекающиеся
  варианты ответа. Удалённые вопросы не заменяются ради формального количества.

## Надёжность генерации

- Неверная или непропорционально раздутая структура останавливается до вызова
  embeddings и генеративной модели.
- Каждый факт большого текстового источника относится ровно к одному уроку;
  границы и порядок разделов сохраняются.
- TypeSafe используется только на синтетических или отдельно обезличенных
  артефактах как дополнительная разработческая оценка качества. Он не входит в
  production-flow, и исходные документы клиентов ему не передаются.

## Проверка релиза

- Полный database-free API unit suite: `1838 passed`; затронутая выборка —
  `158 passed`; 7 проверок `AI-COURSE-01`, Ruff, release/version contracts и
  `git diff --check` прошли.
- Полный Excel «Плюса»: 3 урока, 5 вопросов, 48/48 фактов, 20.775 секунды,
  publishable, без fallback.
- Полный PDF ломбарда: 24 урока, 10 вопросов, 314/314 фактов, 157.321 секунды,
  publishable, без deterministic fallback.
- Независимый read-only review не выявил release-blocking дефектов.

## Развёртывание и откат

- Миграция не требуется; production database revision не изменяется.
- Обновляются API и три worker одним immutable image. Frontend-функциональность
  не меняется и отдельного выпуска CT137 не требует.
- Откат приложения выполняется на immutable release 0.7.1; данные и схема БД
  не меняются.
