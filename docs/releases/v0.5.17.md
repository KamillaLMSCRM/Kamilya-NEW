# Release Notes — 0.5.17

**Product version:** 0.5.17
**Git tag:** `v0.5.17`
**Date:** 2026-09-13

## Для клиентов

- Если сервис построения поискового индекса временно недоступен, читаемый документ
  больше не становится бесполезным для создания курса.
- Перед внешними резервными провайдерами используются три независимые приватные
  реплики Qwen3 Embedding. Отказ одной машины автоматически переводит обработку
  на следующую без изменения формата сохранённых векторов.
- Kamilya явно показывает, что поисковый индекс недоступен, и продолжает генерацию
  по проверенному исходному файлу без выдуманных резервных векторов.
- Повреждённые, пустые и неподдерживаемые документы по-прежнему завершаются ошибкой:
  новый режим применяется только к подтверждённой недоступности всех embedding-
  провайдеров.

## Технические изменения

- Типизированный `AllProvidersFailedError` преобразуется в завершённый degraded-
  результат с `source_ready=true`, `embedding_unavailable=true` и нулевым числом
  записанных векторов.
- Каталог хранит честный статус `partial` и код
  `embedding_providers_unavailable`; `embedding_status` не выдаётся за успешный.
- Дополнительная генерация summary не запускается в degraded-пути, чтобы отказ
  embeddings не заменялся новой зависимостью от внешнего провайдера.
- Порядок global embedding chain: `gx10-12 -> gx10-2 -> gx10-4 -> Voyage ->
  Cohere`. Для gx10-4 передаётся опубликованный им model ID без namespace; все три
  реплики записывают единый канонический embedding-space identity.
- Схема БД и пользовательские данные не изменяются.

## Проверка выпуска

- Узкий регрессионный тест сначала воспроизвёл production-ошибку и затем прошёл на
  исправлении.
- Unit-набор конвертации и деградации: 8 PASS.
- Из VM126 для каждого из трёх приватных маршрутов подтверждены `/v1/models` и
  реальный синтетический `/v1/embeddings`: один конечный вектор размерности 4096.
- До завершения выпуска обязательны полные backend/frontend наборы, exact-SHA CI,
  DEV-readback, production-readback и повторный человеческий прогон полного Excel.

## Откат

API и frontend откатываются на неизменяемые артефакты `0.5.16`. Миграции БД не
требуются и не откатываются.
