# Release Notes — 0.11.131

**Product version:** 0.11.131

**Git tag:** `v0.11.131`

Методист может создавать задания «Порядок действий» в обычных тестах курса и самостоятельных проверках знаний. Ученик расставляет перемешанные шаги. Баллы начисляются, когда порядок всех шагов совпадает с заданным.

При пересдаче порядок показа меняется. В рамках одной попытки перезагрузка сохраняет перестановку в курсе и ранее сохранённый ответ в самостоятельной проверке.

Используется действующая production-схема 0192. Для отката подходит 0.11.130.
