# Release Notes — 0.11.126

**Product version:** 0.11.126

**Git tag:** `v0.11.126`

19 ноября 2026 года.

Методист выбирает языки курса до генерации. При создании из документов русский и казахский включены по умолчанию. Перевод утверждается для конкретной ревизии содержания. У ученика один курс, одно назначение и общий результат. Переключатель языка курса работает отдельно от языка кабинета. Для двух готовых версий письмо о назначении содержит оба языка и одну ссылку.

Новая попытка теста в курсе или самостоятельной проверки знаний получает другой порядок вариантов. После перезагрузки порядок воспроизводится по номеру попытки. Оценка использует прежние идентификаторы ответов.

Production-миграция `0190 → 0191` добавляет таблицу языковых версий с принудительной изоляцией по тенанту. Миграция `0190` модели Luna в production сохраняется. DEV предварительно проверял ту же таблицу под собственной ревизией `0190`; напрямую переносить её номер между ветками нельзя. При откате приложения сохраняются таблица, переводы и результаты. Миграция применяется только через защищённый маршрут с резервной копией и проверкой восстановления.
