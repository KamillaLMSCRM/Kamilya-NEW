# Release Notes — 0.11.4

**Release date:** 2026-09-25

**Product version:** 0.11.4

**Git tag:** `v0.11.4`

## Changed

- Evidence V2 is now the only course-assessment implementation retained in the
  application source tree. Shared Markdown-table parsing and question-quality
  checks remain in active, explicitly owned modules.
- User and engineering documentation now describes the adaptive evidence-axis
  policy: up to three grounded questions per lesson and no weak quota padding.
- Local replay diagnostics expose coverage omissions, question-cap saturation,
  order-independent fingerprints and residual generic-token heuristic impact.

## Fixed

- Architecture tests, prompt inventory and engineering snapshots can no longer
  silently traverse the retired assessment generator, audit or completion path.
- The canonical Windows API test wrapper now exposes both `apps/api` and the
  repository root to pytest while continuing to require the root virtual
  environment.
- Graphify instructions no longer freeze an obsolete workstation version or
  treat a zero exit code without `graphify-out/graph.json` as a usable graph.

## Verification

- Full local API suite: 2853 passed, 499 environment-bound tests skipped and no
  failures.
- Affected Evidence V2 and assessment suite: 338 passed.
- AI-COURSE-01 database-free critical journey: seven passed.
- Ruff, Python compilation and Git diff checks passed.
- Exact-SHA CI, immutable image, synchronized KZ runtime readback and two
  disposable production document-to-course journeys remain release gates.

## Operations

- Database migration: none.
- Frontend functional release: none; only the synchronized product-version
  manifest changes.
- Required production services: API, worker-ops, worker-documents and worker-ai
  on the same immutable backend image.
