# Release Notes — 0.11.150

**Product version:** 0.11.150

**Git tag:** `v0.11.150`

Из каталога курсов можно вернуться к проверке документа. В списке видна дата создания, а карточка курса остаётся видимой при прокрутке на компьютере.

Черновики со связанной историей можно убрать в архив. При сохранении решения оставить исходную формулировку форма показывает требование к основанию.

Проверка документов читает встроенные листы XLSX в Word и сохраняет их на месте таблицы. Миграции базы данных не требуются.
