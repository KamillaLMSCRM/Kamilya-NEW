# Release Notes — 0.7.6

**Release date:** 2026-09-19
**Product version:** 0.7.6
**Git tag:** `v0.7.6`
**Deployed commit:** pending exact-SHA release gate

## Summary

Генератор тестов теперь ограничивает количество вопросов на уровне видимого
урока, удаляет слабые вопросы без искусственного добора и не допускает варианты
ответа, которые отличаются от правильного только типом формулировки.

## Added

- Separate audit counters for all source-derived assessment axes and the subset
  actually submitted for question generation.

## Changed

- At most three source-owned assessment axes are selected per learner-visible
  lesson, round-robin across its semantic blocks.
- A question that still fails the bounded review and one repair attempt is
  recorded as `quality_omitted`; a provider or contract outage remains a
  review-required failure.

## Fixed

- Short categorical keys reject sentence-shaped alternatives from a different
  answer domain.
- Bare numeric keys and numeric distractors use one presentation shape, so the
  correct choice is not exposed by a missing or extra unit suffix.
- The development acceptance runner no longer treats a lightweight admission
  estimate as the worker's authoritative source passport.

## Security

- No authentication, authorization, tenant isolation or secret-handling policy
  change.

## Upgrade / deployment notes

- Database migrations: not required.
- Environment variables added/changed: none.
- Provider routes, DNS, infrastructure and billing: unchanged.
- Frontend/backend deploy order: API and all three application workers from one
  immutable image; native frontend version is synchronized without UI behavior
  changes.
