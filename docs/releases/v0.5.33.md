# Release Notes — 0.5.33

**Product version:** 0.5.33

**Git tag:** `v0.5.33`

**Date:** 2026-09-14

## Для клиентов

- Большой нормативный документ больше не должен прерывать проектирование курса,
  если модель выделила немного больше содержательных тем, чем прежний внутренний
  предел.
- Система принимает до 24 коротких тем карты источника без удаления последних
  тем и использует их для построения структуры курса.
- Это не увеличивает заданное число уроков: темы остаются навигационными
  ориентирами, а фактические уроки по-прежнему проходят отдельную проверку по
  исходному документу и могут быть исключены без искусственного дополнения.

## Технические изменения

- Лимит тем одного source-map record увеличен с 16 до 24 при неизменных лимитах
  размера ответа, суммарного содержимого и итогового architect overview.
- Сервер, а не модель, по-прежнему прикрепляет идентификаторы всех исходных
  фрагментов и проверяет их полное покрытие.
- Пустой список, 25 и более тем, нестроковые или слишком длинные темы и
  превышение сериализованного бюджета остаются безопасными ошибками.
- Схема БД и данные организаций не изменяются.

## Проверка выпуска

- RED-регрессия воспроизводит двукратный production-отказ на 17 корректных темах.
- GREEN принимает все 17 тем одним вызовом без обрезания.
- Связанные source-map и direct-source тесты подтверждают ограничения ответа,
  полное серверное покрытие источников и совместимость с исправлением большого
  OCR-чанка из 0.5.32.
- После exact-SHA deployment повторяются полные production-пути по PDF правил
  ломбарда и должностной инструкции `.doc`.

## Откат

API и frontend откатываются на неизменяемые артефакты версии `0.5.32`.
Изменений БД для отката нет.
