# Release Notes — 0.3.1

**Release date:** 2026-09-09

**Product version:** 0.3.1

**Git tag:** `v0.3.1`

## Исправление настройки согласования курсов

- Флажок отдельного согласования теперь показывает сохранённую настройку курса
  при открытии редактора и переключении между курсами.
- Если настройку не удалось загрузить, интерфейс предлагает повторить попытку,
  а не показывает ошибочно выключенный флажок.
- При блокировке публикации отображается понятная причина и следующий шаг:
  получить решение рецензента либо отключить отдельное согласование, если оно
  не требуется. Сообщения доступны на русском, казахском и английском языках.
- Исправление действует в списке курсов, редакторе и на экране результата генерации.

Отдельное согласование по умолчанию выключено. Проверка сгенерированного курса
методистом сохраняется. Существующие настройки курсов автоматически не изменяются.

Миграция базы данных для этого выпуска не требуется.
