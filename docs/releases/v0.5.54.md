# Release Notes — 0.5.54

**Product version:** 0.5.54

**Git tag:** `v0.5.54`

**Date:** 2026-09-16

## Для клиентов

- Содержательный исходный документ с несколькими самостоятельными темами больше
  не сворачивается в один перегруженный урок. Движок просит минимум два урока,
  только когда анализ источника уверен и материала действительно достаточно.
- Если первичная генерация теста отклонена проверками качества, система может
  восстановить три разных вопроса по трём отдельным подтверждённым фактам. Плохие
  вопросы не сохраняются и искусственно не дополняются.

## Границы исправления

- Маленький источник не растягивается до заданного максимума уроков.
- Служебные листы и каталоги не считаются самостоятельным основанием для
  увеличения курса.
- Восстановление теста ограничено шестью короткими запросами и запускается только
  после попытки охватить минимум три разных допустимых фрагмента источника.

## Проверка кандидата

- Новые дефекты сначала воспроизведены тремя падающими регрессионными тестами.
- Связанный API-набор структуры, оценивания и финальной сборки: 169 тестов — PASS.
- Python quality regression gate: PASS, без новой задолженности Ruff/mypy.
- Полный CI, immutable deployment и повторная генерация в синтетическом тенанте
  обязательны до окончательной приёмки production.

## Откат

- Откат возвращает единый backend image версии 0.5.53 для API и трёх workers.
- Изменений схемы и данных базы нет.
