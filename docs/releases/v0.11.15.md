# Release Notes — 0.11.15

**Release date:** 2026-09-28

**Product version:** 0.11.15

**Git tag:** `v0.11.15`

## Fixed

- Superadmins can delete a disposable or retired tenant after that tenant has
  used source-actuality policies, revision impact analysis and a controlled
  course-update decision.
- Source-actuality reviews and policies are removed before their referenced
  documents and users, preventing foreign-key failures during tenant purge.
- The deterministic DEV controller can resume the same immutable packet after
  a provider build failure without pushing the branch again.
- Render DEV no longer installs Uvicorn's unused hot-reload extra, avoiding a
  hard dependency on `watchfiles` during API builds.

## Security

- Runtime DELETE permission is granted only for the two source-actuality
  tables and only through policies that require the exact tenant context plus
  `app.is_superadmin=true`.
- Existing tenant policies are command-specific for SELECT, INSERT and UPDATE;
  none of them can combine permissively with the superadmin DELETE policy.
- Methodologists and tenant administrators cannot use the purge policy.

- Isolated DEV migration `0165 -> 0166 -> 0165 -> 0166`, FORCE RLS,

## Operations

- Database migration: additive revision `0166`.
- Rollback application: immutable `0.11.14` / Git SHA
  `e3f4e672612fb434365de989137ce5018a2786ea`.
- Database downgrade is permitted only after all application instances have
  returned to `0.11.14`; it drops the two superadmin DELETE policies and
  revokes their DELETE grants without removing source-actuality data.
- No frontend deployment, provider plan, billing, DNS, customer tenant or
  customer document change is required.
