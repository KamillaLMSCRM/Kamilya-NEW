# Release Notes — 0.5.50

**Product version:** 0.5.50

**Git tag:** `v0.5.50`

**Date:** 2026-09-15

## Для клиентов

- Тест больше не сохраняется, если неверный вариант фактически даёт тот же
  ответ на вопрос, что и отмеченный правильный вариант, но добавляет другие
  поясняющие детали.
- В уроки и варианты ответов не пропускаются неуместные разговорные и
  рекламные выражения, обнаруженные при живой проверке курса продавцов.
- Количество вопросов остаётся верхней границей: слабый или неоднозначный
  вопрос удаляется, а не заменяется искусственным вопросом ради количества.

## Надёжность

- Версии политик качества уроков и тестов обновлены, поэтому сохранённые
  промежуточные результаты проходят повторную проверку перед использованием.
- Изменения ограничены серверной проверкой качества; миграций БД и изменений
  frontend-runtime нет.

## Проверка кандидата

- Два точных воспроизведения дефектов сначала подтверждены падающими тестами.
- Профильный backend-набор: 218 тестов — PASS.
- Отдельные новые регрессии и соседние проверки: PASS.

## Откат

- Откат возвращает единый backend image версии 0.5.49 для API и трёх workers.
- База данных и frontend при откате не изменяются.
