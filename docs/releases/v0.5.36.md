# Release Notes — 0.5.36

**Product version:** 0.5.36

**Git tag:** `v0.5.36`

**Date:** 2026-09-14

## Для клиентов

- Если источник не подтверждает часть предварительно предложенных тем, Kamilya
  сохраняет курс только с полезными уроками и не прерывает создание черновика
  на последнем шаге.
- Количество уроков определяется содержанием документа: слабые темы не
  заменяются искусственным наполнением только ради заранее рассчитанного числа.
- Проверка и тесты остаются связаны с теми уроками, которые реально войдут в
  итоговый курс.

## Технические изменения

- Неизменяемая структура плана сохраняется для возобновления контрольных точек.
- Перед проверкой идентичности тестов и записью в БД отдельно строится компактная
  структура из принятых уроков.
- Финальные названия уроков синхронизируются с проверенным содержанием, а
  исходные координаты продолжают использоваться только в checkpoint-хранилище.

## Проверка выпуска

- RED/GREEN-регрессия проходит полный pipeline до границы сохранения после
  исключения второго урока из четырёх.
- 72 проверки direct-source, checkpoint и pipeline проходят локально.
- Полный API unit gate: 1507 тестов успешно.
- После exact-SHA deployment повторяется production-путь методиста по точной
  копии документа ломбарда с замерами и проверкой итогового курса и тестов.

## Откат

Приложение откатывается на неизменяемые артефакты `0.5.35`. Миграций БД в этом
выпуске нет; ревизия production остаётся `0159`.
