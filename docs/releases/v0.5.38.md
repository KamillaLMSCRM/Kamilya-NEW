# Release Notes — 0.5.38

**Product version:** 0.5.38

**Git tag:** `v0.5.38`

**Date:** 2026-09-14

## Для клиентов

- Подробный нормативный или ассортиментный документ больше не отклоняется
  только потому, что в одном фрагменте найдено больше заранее заданного числа
  самостоятельных тем.
- Kamilya сохраняет все темы, которые помещаются в безопасные лимиты ответа,
  вместо искусственного сокращения содержания до 24 пунктов.

## Технические изменения

- Удалён фиксированный верхний предел количества тем в одном source-map batch.
- Сохраняются конечные лимиты размера ответа, полезного текста, JSON-массива,
  токенов, длины каждой темы и итогового обзора архитектора.
- Версия протокола карты источника повышена до `v5`; старые checkpoint-ответы не
  смешиваются с новым контрактом.
- Схема БД не меняется и остаётся на ревизии `0159`.

## Проверка выпуска

- RED/GREEN-регрессия воспроизводит 32 краткие темы: прежний валидатор их
  отклоняет, новый принимает при соблюдении всех размерных бюджетов.
- Профильный source-map/failover gate проходит 70 тестов.
- После exact-SHA deployment повторяется полный production-путь методиста по
  копии документа ломбарда с фиксацией стадий, времени и качества результата.

## Откат

Приложение откатывается на неизменяемые артефакты `0.5.37`; миграций БД нет.
