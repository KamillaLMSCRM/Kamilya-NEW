## User outcome

Methodologists can create an actor-private preparation task from1–5 verified
documents, refine its course brief through successive text instructions, explicitly
save manual parameters and reopen the same saved task after reload. Recent tasks
and their structured exchanges are stored server-side, not in browser localStorage.
The model receives bounded prior instructions and the current brief as untrusted
context. This is preparation of generation parameters, not general document Q&A.

Creating, reading or reopening a task never invokes a model or generation. A
source-bound preview and separate explicit confirmation still use the canonical
document-plan/generation command. Submitted-task reopening restores the same job;
uncertain responses require read recovery. Changed source scope/language starts a
new task; changed source metadata fails closed while private history stays readable.

No voice, reserve activation, provider-order change, new paid resources, tenant
recreation, customer-data changes, publication or assignment from prose.
