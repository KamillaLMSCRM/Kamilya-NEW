# Release Notes — 0.5.23

**Product version:** 0.5.23
**Git tag:** `v0.5.23`
**Date:** 2026-09-13

## Для клиентов

- Если для отдельного урока модель не смогла сформулировать ни одного качественного
  вопроса, Kamilya сохраняет сам урок без теста и продолжает создание курса.
- Система не перегенерирует слабые вопросы ради количества и не отменяет из-за них
  весь уже подготовленный курс.
- После перезапуска фоновой задачи решение оставить урок без теста сохраняется и не
  приводит к повторным расходам на модель.

## Технические изменения

- Путь фильтрации структурированных источников теперь допускает ноль оставшихся
  вопросов для конкретного урока.
- Пустой assessment-checkpoint принимается только для табличного источника; обычные
  неструктурированные источники сохраняют прежнее fail-closed поведение.
- Схема БД, пользовательские данные и интерфейс не изменяются.

## Проверка выпуска

- Production-проверка `0.5.22` воспроизвела сбой полного Excel на этапе assessment
  85%; runtime-журнал подтвердил исчерпание пяти попыток валидации.
- RED-регрессия воспроизвела пять ненужных вызовов и общий `ValueError`.
- После исправления урок сохраняется с нулём вопросов за один вызов, а checkpoint
  восстанавливается без обращения к провайдеру.
- Полный API unit-набор, version gate, exact-SHA CI, production deployment и новая
  генерация полного Excel являются обязательными gate выпуска.

## Откат

API откатывается на неизменяемый backend-артефакт `0.5.22`. Изменений БД и
frontend-кода в выпуске нет.
