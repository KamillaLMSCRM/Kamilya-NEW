# Release Notes — 0.6.1

**Product version:** 0.6.1

**Git tag:** `v0.6.1`

**Date:** 2026-09-16

## Для клиентов

- Сотрудник получает полноценный PDF-бланк подтверждения прохождения и для
  курсов, завершённых до появления настраиваемой печатной формы.
- Для нового завершения используется шаблон, зафиксированный в момент
  прохождения; для исторического завершения без такого снимка применяется
  текущий шаблон организации.

## Проверка кандидата

- Database-free RED/GREEN-тест воспроизводит историческое событие без
  `print_form` и проверяет применение текущего tenant-шаблона только в learner
  PDF.
- DB-backed integration проверяет публичный learner endpoint и наличие на
  последней странице PDF полей подписи сотрудника и представителя работодателя.
- Полный CI и живой синтетический production-путь обязательны для точного SHA.

## Безопасность и данные

- Неизменяемое событие прохождения и private evidence package не переписываются.
- События с сохранённым snapshot формы не зависят от последующих изменений
  tenant-настроек.
- Fallback применяется только к learner PDF исторического события типа
  `training`; tenant/RLS и ownership-проверки остаются прежними.

## Развёртывание

- Миграции базы данных и новые переменные окружения не требуются.
- API, workers и native frontend выпускаются из одного точного SHA.

## Откат

- Приложение можно вернуть на `v0.6.0` без изменения схемы базы данных.
