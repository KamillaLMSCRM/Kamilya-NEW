# Release Notes — 0.5.26

**Product version:** 0.5.26
**Git tag:** `v0.5.26`
**Date:** 2026-09-13

## Для клиентов

- При создании курса из Excel некорректные и повторяющиеся вопросы удаляются,
  а не заменяются новыми только ради заданного количества.
- Количество уроков и тестовых вопросов является верхней границей. Если в
  источнике недостаточно разных полезных фактов, курс может быть короче.
- Валидные вопросы и уроки сохраняются; отдельный урок может остаться без теста,
  если надёжных вопросов для него нет.

## Технические изменения

- Единая политика фильтрации структурированных источников теперь распознаёт как
  Markdown-таблицы, так и строки Excel, представленные в виде `поле — значение`.
- Повторные обращения к модели используются для неразбираемого ответа, но не для
  искусственного заполнения квоты после успешного разбора.
- Схема БД, пользовательские данные и frontend-код не изменяются.

## Проверка выпуска

- Детерминированный replay воспроизводит прежние пять обращений к модели без
  внешней сети и подтверждает один вызов после исправления.
- Отдельные тесты проверяют частичную фильтрацию, полностью пустой тест,
  межурочные повторы и восстановление сохранённого прогресса.
- Полный API unit-набор, CI, DEV-проверка и одна финальная генерация исходного
  Excel в production являются последовательными воротами выпуска.

## Откат

API откатывается на неизменяемый backend-артефакт `0.5.25`. Изменений БД и
frontend-кода в выпуске нет.
