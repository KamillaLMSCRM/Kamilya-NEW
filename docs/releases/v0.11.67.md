# Release Notes — 0.11.67

**Product version:** 0.11.67
**Git tag:** `v0.11.67`
**Status:** Prepared locally; release and production acceptance pending.

## Scope

This frontend-only candidate improves course authoring, assignments, learner
navigation, evidence confirmation and scoped training results. It preserves
session boundaries on explicit session replacement while retaining work during
ordinary token refresh.

The production API and workers remain on version 0.11.66. The API manifest
version is updated only to satisfy repository version lockstep; no backend
runtime, database migration, model routing or provider configuration change
is included.

## Validation and release gates

The predecessor frontend candidate passed local tests, lint, typecheck, a
synthetic build and intercepted browser journeys. Those results do not prove
this versioned successor has passed exact-SHA CI, native artifact verification,
production deployment or live business acceptance. Complete those gates and
verify rollback and available capacity before release.
