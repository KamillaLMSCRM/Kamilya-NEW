# Release Notes — 0.11.21

**Product version:** 0.11.21
**Git tag:** `v0.11.21`
**Date:** 2026-09-30

## Что изменилось

- Исправлено отображение страницы назначений на узких экранах: длинные названия
  курсов больше не растягивают карточки и всю страницу за пределы экрана.
  Таблица назначений сохраняет собственную горизонтальную прокрутку.
- Сохранены улучшения 0.11.20: переходы по неудачным проверкам и исчерпанным
  попыткам, точное открытие выбранного назначения, фактический срок и безопасный
  следующий шаг сотрудника, одинаковый отбор в журнале, сводке и CSV.
- Зафиксирована безопасная процедура проверки release-lock. Существующий lock,
  включая пустой, блокирует запуск без изменения рабочего контура.

## Совместимость и проверка

Миграций базы нет; схема остаётся `0168`. API и три рабочих процесса получают
тот же функциональный backend с согласованной версией. Обновления безопасности
PyJWT 2.14.0 и urllib3 2.8.0 сохранены, блокирующий аудит не ослабляется.

Production-приёмка использует существующий синтетический tenant без изменения
клиентских данных, писем, AI-вызовов или тарифов провайдеров. Не создаёт и не
удаляет tenant при каждом запуске. Точные результаты и ограничения проверки
фиксируются после выпуска в каноническом реестре production-гейтов.

## Откат

Предыдущий production API/worker-образ и каталог интерфейса сохраняются для
контролируемого отката. Выпущенный тег 0.11.20 не переписывается.
