# Release Notes — 0.11.74

**Product version:** 0.11.74

**Git tag:** `v0.11.74`

Methodologists can check a document before creating a course. The system
automatically corrects verified spelling and formatting errors. An independent
check flags source wording that leaves a material choice unresolved. The
methodologist sees the relevant original excerpts and can also correct a missed
passage with a reason. An approved edition is required for new document-based
course generation.

The original stays intact. The history shows automatic edits, human decisions
and reversals. Each generation job uses the specific edition it was admitted
with, even if the document review is reopened later.

Database revision 0185 adds an append-only review history. Application rollback
retains this table; do not downgrade the database after accepting review records.
