# Release Notes — 0.5.4

**Release date:** 2026-09-12
**Product version:** 0.5.4
**Git tag:** `v0.5.4`

## Customer-visible changes

- A large workbook can use its main learning worksheet as the course foundation
  while still drawing exact examples and attributes from an auxiliary catalog.
- Price, identifier and article-number columns no longer make an otherwise
  educational worksheet auxiliary by themselves.
- Catalog lists cannot silently become course, module, lesson or objective topics;
  their facts are admitted only as source-linked supporting detail.

## Safety and compatibility

- Worksheet identity is checked together with its source document, preventing
  same-named sheets from being confused across uploaded files.
- Generated courses and tests remain drafts for methodologist review before
  publication.
- Existing courses, source documents, tenant limits, provider order and
  authentication behavior are unchanged.
- No database migration is required; schema revision remains `0158`.
