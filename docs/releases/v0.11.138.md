# Release Notes — 0.11.138

**Product version:** 0.11.138

**Git tag:** `v0.11.138`

В визуальном редакторе урока появился блок «Таблица». Методист может изменить ячейки и заголовки, добавить или удалить строки и столбцы. Ранее созданные Markdown-таблицы из уроков открываются в том же редакторе.

Фронтенд использует действующий API 0.11.136 и схему 0192. Для отката сохранена предыдущая сборка фронтенда 0.11.137.
