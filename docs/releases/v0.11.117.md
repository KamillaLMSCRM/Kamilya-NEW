# Release Notes — 0.11.117

**Product version:** 0.11.117
**Git tag:** `v0.11.117`

ENG-074: начальный выбор частей исходника сохраняет учебные материалы и
дополнения вместе. Справочный каталог остаётся доступным движку как источник;
административные части не включаются автоматически. Явный выбор методиста,
утверждённые редакции и их история сохраняются без изменений.

Существующий планировщик группирует материал по смысловым темам и навыкам.
Товарные строки используются как основания и дополнения к соответствующим
урокам, без требования создавать отдельный урок на каждый артикул.

Миграций, смены моделей, reasoning, тарифов и provider routing нет.
Клиентские исходники, курсы и результаты сотрудников не изменяются.
Полный путь на реальном Excel проверяется на отдельной копии в постоянном DEV
QA-тенанте. LOCAL/DEV/production результаты фиксируются отдельно; наличие этого
файла не означает, что выпуск уже принят или развёрнут.
