# Release Notes — 0.5.46

**Product version:** 0.5.46

**Git tag:** `v0.5.46`

**Date:** 2026-09-14

**Статус:** локальный кандидат. CI, DEV, immutable deployment и production
readback фиксируются отдельно.

## Для клиентов

- При создании ещё одного курса из уже использованного документа подтверждение
  причины теперь является частью одного нормального пользовательского действия:
  второе нажатие не блокируется ошибкой ограничения частоты запросов.
- Вопросы к уроку проверяются не только на наличие факта в общем источнике, но и
  на принадлежность теме конкретного урока. Например, срок рассмотрения жалобы
  не попадёт в урок о рассмотрении заявления на микрокредит.
- Вопрос из соседнего раздела удаляется без генерации замены только ради
  количества. Корректный текст урока при этом не переписывается.

## Проверка кандидата

- Полный API unit-suite: 1694 теста — PASS.
- Связанный контур assessment/direct-source/rate-limit: 357 тестов — PASS.
- Новые тематические регрессии: 7 тестов — PASS; проверены «заявление ↔ жалоба»,
  «АРК ↔ выплата вознаграждения», «права клиента ↔ обязанности ломбарда»,
  положительный парафраз и повторная проверка восстановленного checkpoint.
- Первый более широкий вариант фильтра был отклонён до выпуска: он ломал пять
  существующих сценариев. В релиз включён только ограниченный direct-source
  вариант, совместимый с полным unit-suite.

## Ограничения и откат

Сгенерированный курс остаётся редактируемым черновиком и требует проверки
методистом перед публикацией. Выпуск не меняет схему БД, DNS, инфраструктуру,
модельные маршруты, тарифы или лимиты расходов. Откат возвращает API, workers и
нативный frontend на неизменяемые артефакты 0.5.45.
