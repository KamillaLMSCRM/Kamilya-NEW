# Release Notes — 0.5.11

**Release date:** 2026-09-12
**Product version:** 0.5.11
**Git tag:** `v0.5.11`

## Customer-visible changes

- Long document indexing and course generation show measured progress and an
  updated remaining-time estimate in the tenant interface. This frontend code
  was introduced in `63ed5fd8` after the previous CT137 deployment
  (`a507e17b`) and is included by deploying the complete 0.5.11 tree.
- The production frontend is synchronized with the already deployed course
  quality and generation-reliability updates.

## Safety and compatibility

- Removed the retired legacy LMS/CDN hostnames from active browser and API
  security policies. Production browser connections use `api.kml.kz`; the
  separately built DEV frontend derives its Render API origin without adding
  that origin to production CSP.
- No database migration or provider-setting change is required. The release
  updates the API and all workers on VM126 plus the native frontend on CT137.
- `mail.kml.kz`, Resend DNS, WhatsApp gateway, tenant data and billing remain
  unchanged.
