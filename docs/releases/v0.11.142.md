# Release Notes — 0.11.142

**Product version:** 0.11.142

**Git tag:** `v0.11.142`

Поиск в «Назначениях» показывает сотрудников, которым курс уже назначен, и открывает их действующие назначения. Поиск доступен и при коротком списке назначений.

Выпуск фронтенда совместим с API 0.11.140 и схемой 0192.
