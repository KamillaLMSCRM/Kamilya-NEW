# Release Notes — 0.11.149

**Product version:** 0.11.149

**Git tag:** `v0.11.149`

Настроены клавиатурное переключение способов входа и мобильное меню. Вход и демо используют оформление кабинета методиста.

Одобрение и публикация доступны в шапке редактора. Рабочее место загружает источники при первом открытии вкладки «Документ» и сохраняет форму при переключении.

Выпуск веб-интерфейса совместим с API 0.11.148 и схемой 0194.
