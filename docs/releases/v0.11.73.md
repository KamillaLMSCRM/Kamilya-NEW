# Release Notes — 0.11.73

**Product version:** 0.11.73
**Git tag:** `v0.11.73`

The course editor shows the path from reviewing the draft to assigning a published course. The review link opens the tests for that course. Publication makes the assignment link available with the course already selected.

After the last test, the next action takes the learner to the course completion button. The completion screen shows the result and the certificate together, with documentary confirmation below. If the confirmation record cannot load, the learner can still see the course result and open the certificate.

The assignment form displays the personal link's validity and completion limits in a compact summary. Open the additional settings to adjust them.
