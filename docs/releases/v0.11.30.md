# Release Notes — 0.11.30

**Product version:** 0.11.30. Local candidate; not published or deployed.
**Git tag:** `v0.11.30` — planned, not yet created.

One bounded production-client usability and accessibility repair package.
Contextual help describes real controls, role permissions and prerequisites,
not invented actions. Document empty states distinguish filters and lifecycle
views; forms expose accessible labels; quiz settings describe configured limits;
workbench starts blank and localizes its UI while explicitly retaining the
Russian-only command grammar and preview/confirmation contract. Nested navigation,
recurrence prerequisites and deadline-history wording are corrected. AI-chat
controls and modal keyboard handling are accessible; public login has one
localized skip link.

Platform overview no longer proposes launching the first tenant when existing
tenants are present or the tenant list is loading/failed. Platform tenant and
provider-key forms expose labels without changing permissions or provider calls.
Platform requests reuse the existing session-aware API transport rather than
failing silently after access-token expiry. Tenant wizard first-step prerequisites
are validated before advancing; no account, tariff or role is changed by this fix.

Governance strengthens bounded CodeGraph use, freshness checks and source
verification. A small navigation pilot measures full process latency, not
engineering throughput or subscription savings. ECC is selective workflow
practice, not a newly installed plugin. CodeBurn day aggregates do not prove
current-turn or delegated-agent savings.
