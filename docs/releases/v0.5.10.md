# Release Notes — 0.5.10

**Release date:** 2026-09-12
**Product version:** 0.5.10
**Git tag:** `v0.5.10`

## Customer-visible changes

- Course generation continues to use DeepSeek first and now has a verified
  private Qwen 3.8 fallback when the primary provider is unavailable.
- Document indexing continues through the private Qwen embedding route with
  Voyage and Cohere fallbacks.
- No model endpoint needs to be exposed through a public Kamilya hostname.

## Safety and compatibility

- Model discovery and a real synthetic chat completion were verified from
  VM126 through the private KZ WireGuard route.
- The obsolete public legacy-Qwen defaults were removed; the legacy model is
  not part of the customer-facing generation chain.
- Tenant-owned provider configuration remains unchanged.
- No database migration is required; schema revision remains `0158`.
