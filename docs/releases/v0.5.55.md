# Release Notes — 0.5.55

**Product version:** 0.5.55

**Git tag:** `v0.5.55`

**Date:** 2026-09-16

## Для клиентов

- Автоматический режим больше не сворачивает содержательный регламент в один
  перегруженный урок только потому, что методист не задавал число уроков вручную.
- Обычный текстовый документ теперь проходит ту же проверку подтверждённых
  учебных действий, что и структурированный Excel, без ложного отказа из-за
  отсутствия листов.
- Если первичный пакет вопросов оказался невалидным, но использовал хотя бы один
  реальный фрагмент источника, система может восстановить до трёх разных
  доказательных вопросов по отдельным фрагментам.

## Границы исправления

- Маленький документ и сильно повторяющийся каталог не растягиваются до двух
  уроков ради количества.
- Вопросы с неизвестным фрагментом, пустой ответ модели и слабые вопросы не
  сохраняются и не запускают бессмысленную серию дополнительных запросов.
- Отдельный урок может остаться без теста, если ни один вопрос не проходит
  детерминированную проверку качества; курс не дополняется выдуманными вопросами.

## Проверка кандидата

- Три production-симптома сначала воспроизведены красными тестами: автоматический
  одноурочный план, пустой набор допустимого текста для prose и повтор одного
  evidence-ID в полностью отклонённом пакете вопросов.
- Связанный набор структуры и оценивания: 220 тестов — PASS.
- Production-подобный локальный прогон на том же синтетическом регламенте:
  архитектор — 2 модуля / 5 уроков за один вызов; writer сохранил 4 урока за
  24,37 с; оценивание сформировало 7 валидных вопросов за 43,79 с.
- Полный CI, immutable deployment и повторная генерация в синтетическом тенанте
  обязательны до окончательной приёмки production.

## Откат

- Откат возвращает единый backend image версии 0.5.54 для API и трёх workers.
- Изменений схемы и данных базы нет.
