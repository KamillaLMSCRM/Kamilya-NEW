# Release Notes — 0.5.56

**Product version:** 0.5.56

**Git tag:** `v0.5.56`

**Date:** 2026-09-16

## Для клиентов

- Обычный текстовый регламент с нумерованными разделами больше не сворачивается
  в один перегруженный урок: система сохраняет структуру источника и объединяет
  соседние разделы в понятные учебные блоки.
- Количество уроков определяется объёмом и фактическим содержанием документа.
  Небольшой источник не растягивается ради квоты, а содержательный документ не
  теряет самостоятельные темы.
- Сроки, проценты и другие проверяемые значения выделяются в отдельные факты.
  Вопрос сохраняется только при наличии однозначного ответа и безопасных
  вариантов из того же источника.
- Повторный вопрос на уже проверенный факт удаляется, а не заменяется вопросом
  «для количества».

## Проверка кандидата

- Точный production-симптом сначала воспроизведён через активный Evidence V2:
  исходный результат составлял один урок и ноль вопросов.
- После исправления тот же источник стабильно даёт пять уроков и семь вопросов,
  включая отдельные вопросы про 15 минут, 1 час и 4 рабочих часа.
- Реальный локальный provider-прогон завершился за 29,110 секунды через Voyage
  embeddings без деградации и без детерминированного fallback; итоговый черновик
  прошёл publishability-проверку.
- Полный backend unit-набор: 1770 тестов — PASS. Python quality baseline и
  database-free critical journey — PASS.
- Полный CI, immutable deployment и повторная генерация в синтетическом тенанте
  обязательны до окончательной приёмки production.

## Границы исправления

- Исправление относится к backend-конвейеру преобразования источника, планирования
  уроков и тестов. Пользовательский интерфейс в этом выпуске не меняется.
- Если для утверждения невозможно подобрать два безопасных отвлекающих варианта,
  вопрос не создаётся; система не дополняет тест выдуманными фактами.

## Откат

- Откат возвращает единый backend image версии 0.5.55 для API и трёх workers.
- Изменений схемы и данных базы нет.
