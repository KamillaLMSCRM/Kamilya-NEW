# Release Notes — 0.11.11

**Release date:** 2026-09-27

**Product version:** 0.11.11

**Git tag:** `v0.11.11`

## Added

- A deterministic bridge now executes routine digest-bound CT137 release
  packets without asking an LLM to reconstruct the deployment sequence.
- A deterministic DEV controller binds GitHub CI, Vercel, Render API, Render
  worker and public health evidence to one exact source SHA.
- CI now compiles both controllers and runs their focused contract suites.

## Changed

- The Release Runner uses deterministic controllers for the normal success
  path and retrieves wider project context only for explicit exceptions.
- DEV-only releases no longer enter CT137, SSH or production-host checks.

## Verification

- The complete focused release and governance suite passes 45 tests.
- The release-contract gate passes with the repository migration head,
  Celery wiring, migration ownership and Render dependency contracts intact.
- The DEV controller completed a real exact-SHA release on GitHub CI, Vercel,
  Render API and Render worker, followed by public health readback.
- Exact project-account push, remote SHA readback, successful master CI,
  matching tag and published GitHub Release are mandatory publication gates.

## Operations

- Database migration: none.
- API, worker and frontend runtime behavior: unchanged.
- No VM126 or CT137 runtime rollout is required; the immutable production
  runtime and rollback remain untouched.
- No provider plan, billing, DNS, database or customer-data change is required.
