# Release Notes — 0.11.14

**Release date:** 2026-09-28

**Product version:** 0.11.14

**Git tag:** `v0.11.14`

## Added

- Methodologists can assign an owner and review schedule to a source family,
  compare its latest active revision with the previous one, and see the affected
  courses, lessons and assessments.
- The documents page provides the complete review and decision flow in Russian,
  Kazakh and English.

## Changed

- A source update can create a separate reviewable course draft, but it never
  overwrites a published release, republishes a course or reassigns employees
  automatically.
- Change analysis uses the production direct-source converter and deterministic
  Evidence V2 facts; it does not require a generative-model request.

## Fixed

- Analysis is limited to the latest active source revision and remains safe if a
  newer revision appears while a worker is running.
- Course-level provenance marks every affected lesson and quiz for review, while
  unrelated source references remain attached to the draft.
- Empty review dates remain empty, and database-updated review timestamps are
  materialized before the asynchronous API response is serialized.
