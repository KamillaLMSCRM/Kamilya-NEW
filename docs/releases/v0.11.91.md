# Release Notes — 0.11.91

**Product version:** 0.11.91
**Git tag:** `v0.11.91` (not created at local preparation)

New-course generation now has three meaningful model stages: author directly from the structured approved document, one editor reviewing from source to course, and addressed revision. It does not call the legacy semantic cascades. A rejected prototype summarized the source before authoring and lost/reparented an operative condition; that intermediate representation and its unused native stage were removed.

The author teaches operative decisions, actions and records under their original conditions. The reviewer checks lesson bodies independently of test explanations and solves the questions before checking their keys. The editor preserves good content, source illustrations and approved interpretations. Reviews and actual changes are retained. Only genuinely incompatible source interpretations call for human clarification; model approval is not publication approval.

Existing source ownership, approved revisions, journal leases, unknown-outcome fences and raw/normalized response custody remain. Source spans are exact provenance, not proof of semantic coverage. Persist separate spans rather than quoting unselected intervening text. Preserve references to long source sections without importing the separate correction tool's aggregate prompt limit; that tool's own limits remain an explicit limitation. Existing jobs keep old policy handling and are not silently replayed under the new controller.

Local evidence: `docs/testing/2026-11-11-simple-course-editor.md`. The full production gate requires exact CI/image, ordinary DEV course quality/recovery and DeepSeek acceptance, current rollback and synthetic live readback. No migration, provider plan/resource/routing change, customer-data mutation or native production frontend deployment is included. Local test success does not satisfy those runtime gates.
