# 0.11.51 — долговременный диалог по уроку

Статус: кандидат; выпуск и живая приёмка ещё не выполнены.

Методист сможет после перезагрузки снова открыть помощника того же урока,
прочитать сохранённое обсуждение и продолжить его уточняющим вопросом.
Переписка разделена по методисту, организации, курсу, уроку и языку.
Ранее закрытые диалоги0.11.50, которые существовали только в памяти вкладки,
задним числом восстановить нельзя.

История листается по20 завершённых обменов; модель получает не весь архив,
а до4 последних допустимых обменов в прежнем ограниченном бюджете. Сохранённый
ответ — не проверенный источник и не разрешение на изменение урока. Архивные
предложения доступны как текст без кнопки применения. Свежий ответ можно
проверить по документам через существующий отдельный предпросмотр/подтверждение.

Потеря сетевого ответа не запускает повторную генерацию. Обновление истории
показывает сохранённый результат, обработку либо явное прерывание. Запрос с тем
же ключом возвращает уже сохранённый ответ без второго вызова модели.

Техническая граница: additive0179, приватная таблица с FORCE RLS и штатным
удалением вместе с её владельцем. Предыдущий API совместим с новой таблицей;
откат приложения не удаляет переписку. Downgrade заполненного архива запрещён.
Перенос урока во время ответа не создаёт результат для устаревшей связи.
Провайдеры, модели, тарифы, голос, роли, назначения и завершённое обучение не
меняются. Реальная семантическая точность остаётся предметом проверки методиста.

Локальные focused/API/интерфейсные проверки и изолированный DEV проходят по
контрактам EDITOR_DURABLE_LESSON_DIALOGUE_V1/V1.1; окончательные counts/SHA/CI,
DEV/provider/schema и production/browser evidence будут зафиксированы после
выполнения. Наличие этого файла не является публикацией или product GO.
