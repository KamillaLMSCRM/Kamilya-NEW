# Release Notes — 0.11.77

**Product version:** 0.11.77

**Git tag:** `v0.11.77`

Production source checks use the saved DeepSeek and Luna route. Production
generation settings only offer these two models; the worker cannot fall back
to a development model. When the approved providers cannot complete a source
check, the check reports that failure for the methodologist to retry.

Backend-only release. No database migration or frontend deployment is required.
