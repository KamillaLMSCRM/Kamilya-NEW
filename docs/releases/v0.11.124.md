# Release Notes — 0.11.124

**Product version:** 0.11.124

**Git tag:** `v0.11.124`

The runtime settings catalog accepts Luna 6. The audited setting controls
both normal request identity and administrative readiness. A model change
requires the selected private connector to report the same model and protocol.
New connectors default to Luna 6. Explicit legacy deployments and stored 5.6
receipts stay readable during the transition. DeepSeek remains first and its
key probe uses the same effective model and request deadline as generation.

Migration 0188 → 0190 expands one existing setting constraint. It does
not write the value, change roles, or alter existing settings history.
The runtime-switch operation follows the compatible application/database
release and authorized connector upgrade. It records the model through
the existing superadmin runtime settings API with current revision and
reason. Keep the earlier connector image and its configuration for rollback.
Switch the connector back, revert the runtime value through the audited API,
and verify readiness before any database downgrade. The older application
cannot show history containing a Luna 6 entry, so retain a compatible
application for provider rollback.

The separate DEV engine contour already includes 0189. Exercise 0190 in
an owned Supabase DEV schema first. Keep the public DEV migration chain and
the deferred engine untouched until a compatible release chain is agreed.
