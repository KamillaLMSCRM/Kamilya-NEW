# Release Notes — 0.11.148

**Product version:** 0.11.148

**Git tag:** `v0.11.148`

Движок сохраняет доступ к строкам согласованного каталога. Для явного запроса строк действует тот же лимит, что и для автоматического выбора. Редактор получает контекст урока и соседние вопросы для адресной корректировки.

Выпуск обновляет API и воркеры. Схема 0194 добавляет два параметра каталога в существующий механизм runtime_settings.
