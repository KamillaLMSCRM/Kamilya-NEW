# Release Notes — 0.5.0

**Release date:** 2026-09-11
**Product version:** 0.5.0
**Git tag:** `v0.5.0`

## Customer-visible changes

- Course size and estimated learning duration adapt to the amount of usable
  information in the selected materials.
- Interrupted generation can continue from saved progress instead of restarting
  completed lessons, reviews, and tests.
- Large document and spreadsheet generation gets one bounded correction when the
  first AI response does not satisfy the requested course structure.
- A browser session requires a new password sign-in after at most eight hours,
  including when the site was left open overnight.

## Compatibility

- Migration `0158` is additive.
- Existing completed courses and source documents are unchanged.
- Existing refresh sessions older than the new eight-hour limit are rejected on
  their next refresh and return the user to sign-in.
