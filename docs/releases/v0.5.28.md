# Release Notes — 0.5.28

**Product version:** 0.5.28
**Git tag:** `v0.5.28`
**Date:** 2026-09-13

## Для клиентов

- Старые документы Microsoft Word в формате `.doc` теперь индексируются и могут
  использоваться как источники курсов наряду с DOCX, PDF и Excel.
- Окно редактирования урока действительно использует доступную ширину экрана:
  исходный текст и безопасный форматированный предпросмотр видны рядом.
- В предпросмотре заголовки, списки и таблицы отображаются без служебных символов
  Markdown; исходный текст при сохранении не изменяется.

## Технические изменения

- Каждая конвертация `.doc` получает отдельный временный профиль LibreOffice.
  Это устраняет ошибку первого запуска непривилегированного контейнерного
  пользователя и не допускает общих lock-файлов между параллельными запросами.
- Ширина диалога редактора явно пересиливает узкое значение общего UI-компонента;
  мобильная одноколоночная раскладка сохранена.
- Схема БД и данные организаций не изменяются.

## Проверка выпуска

- Регрессионный тест воспроизводит отсутствие изолированного профиля и требует
  точный `UserInstallation` внутри временного каталога конвертации.
- Тест редактора требует фактически приоритетный широкий класс, безопасный
  предпросмотр и неизменное сохранение исходного Markdown.
- Финальная production-приёмка выполняется реальным бинарным `.doc`, сканированным
  PDF ломбарда и созданием курсов через обычный интерфейс методиста.

## Откат

Frontend и API откатываются на неизменяемые артефакты версии `0.5.27`. Для
Docling сохраняется предыдущий рабочий образ; изменений БД для отката нет.
