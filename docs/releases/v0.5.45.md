# Release Notes — 0.5.45

**Product version:** 0.5.45

**Git tag:** `v0.5.45`

**Date:** 2026-09-14

**Статус:** локальный кандидат прошёл полный API unit-suite, сборку фронтенда,
статические проверки и содержательное воспроизведение полного контрольного
Excel-файла. CI, DEV и production-приёмка фиксируются отдельно.

## Для клиентов

- Большая сравнительная таблица теперь превращается в отдельные уроки по
  названным сущностям. Похожие названия, например «Чикаго Нео» и
  «Чикаго Стрит», не смешиваются между собой.
- Вспомогательные листы помогают раскрыть материал, но не заставляют систему
  искусственно увеличивать количество уроков или строить курс по номенклатурному
  списку вместо основного учебного листа.
- Вопрос сохраняется только тогда, когда он относится к текущему уроку и имеет
  один подтверждённый источником ответ. Сомнительные, повторные и относящиеся к
  другой сущности вопросы удаляются без замены ради количества.
- Прогресс показывает точное число завершённых уроков и общее число уроков
  текущего курса. После сохранения черновика остаётся фактический итоговый счётчик.
- Если принудительное обновление просроченной сессии не удалось, интерфейс
  очищает устаревший контекст и возвращается к штатной авторизации.

## Ограничения и откат

Сгенерированный курс остаётся редактируемым черновиком и требует проверки
методистом перед публикацией. В выпуске нет миграций, изменений DNS,
инфраструктуры или маршрутов моделей. Откат возвращает API, workers и нативный
фронтенд на неизменяемые артефакты 0.5.44.
