# Release Notes — 0.5.5

**Release date:** 2026-09-12
**Product version:** 0.5.5
**Git tag:** `v0.5.5`

## Customer-visible changes

- Large Excel sources with wide comparison tables are processed without hidden
  row truncation and retain the meaning of each field and collection.
- When the main worksheet contains the learning logic and another worksheet is
  only a product list, the course continues to follow the main worksheet.
- Compact lessons now receive a proportionate number of questions instead of
  being padded with repetitive or presentation-driven wording.
- Source notes and technical annotations are excluded from learner-facing
  lesson topics.

## Safety and compatibility

- Generated courses and tests remain drafts for methodologist review before
  publication.
- Existing courses, source documents, tenant limits, AI provider order and
  authentication behavior are unchanged.
- No database migration is required; schema revision remains `0158`.
