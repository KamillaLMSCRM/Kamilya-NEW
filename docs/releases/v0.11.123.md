# Release Notes — 0.11.123

**Product version:** 0.11.123

**Git tag:** `v0.11.123`

PowerPoint source review retains embedded PNG and JPEG screenshots, slide order,
native text, tables and presenter notes. Screenshot-only slides can contribute
to the approved source. Locations and original image bytes remain available for
source evidence and the generated course. Unsupported linked or materially
cropped pictures still need a supported original.

DEV image reading uses the same verified Luna route as source text. The
private connector handles bounded attached images while maintaining its text
protocol. Its image-build receipt records the installed, verified CLI.

This package is based on production 122 with no schema change. The production
provider order and the separate DEV course engine are outside its scope.
