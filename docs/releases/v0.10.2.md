# Release Notes — 0.10.2

**Release date:** 2026-09-23

**Product version:** 0.10.2

**Git tag:** `v0.10.2`

## Для клиентов

Генерация курса точнее следует смысловым разделам исходного документа. Если
материала мало, система не добавляет уроки и вопросы ради заданного количества.
В табличных источниках характеристики остаются привязаны к своей коллекции и
названию поля; вспомогательная номенклатура не превращается в отдельную тему.

При проверке вопросов система отсеивает варианты, относящиеся к другой
ситуации, и не выдаёт повторяющиеся формулировки правила за новый материал.
Полученный курс по-прежнему остаётся черновиком для проверки методистом до
публикации.

## Техническая граница

Новая миграция БД, переменные окружения, тарифы и платные ресурсы не нужны.
Обновляются API и три worker'а; frontend синхронизируется по версии и SHA без
изменения пользовательского интерфейса. Предыдущий immutable release должен
оставаться доступным для отката.
