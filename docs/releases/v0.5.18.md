# Release Notes — 0.5.18

**Product version:** 0.5.18
**Git tag:** `v0.5.18`
**Date:** 2026-09-13

## Для клиентов

- Kamilya удаляет повторный вопрос, если он другими словами проверяет тот же факт
  из той же ячейки исходной таблицы.
- Вариант ответа не сохраняется как неправильный, если исходный материал также
  подтверждает его как подходящий ответ на этот вопрос.
- Непонятные компактные сокращения из Excel не попадают в варианты ответа, если
  курс не обучает работе с такими кодами явно.
- Количество вопросов является целевым максимумом, а не обязательной нормой.
  Небольшой урок получает короткий качественный тест без выдуманных вопросов и
  искусственного повторения материала.

## Технические изменения

- Для структурированного источника факт идентифицируется по серверному evidence ID
  и конкретной ячейке, поддерживающей правильный ответ.
- Проверка неоднозначности учитывает не только дословный фрагмент, но и короткую
  подтверждаемую тем же исходным значением формулировку.
- После фильтрации дубликатов, неоднозначных вариантов и непрозрачных сокращений
  валидная часть теста сохраняется сразу; дополнительный запрос к модели не
  выполняется ради заполнения количества.
- Схема БД и пользовательские данные не изменяются.

## Проверка выпуска

- Четыре регрессии сначала воспроизвели дефекты production-курса и затем прошли на
  исправлении.
- Полный API unit-набор: 1473 PASS.
- Native frontend helper: 21 PASS, 19 platform-specific SKIP, 9 subtests PASS.
- Локальный критический путь `AI-COURSE-01`: 5 PASS; один DB-тест оставлен
  каноническому CI/Supabase DEV-контуру.
- Exact-SHA CI, защищённый production deploy и повторная браузерная генерация
  полного Excel являются обязательными последующими gate выпуска.

## Откат

API и frontend откатываются на неизменяемые артефакты `0.5.17`. Миграции БД не
требуются и не откатываются.
