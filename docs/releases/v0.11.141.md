# Release Notes — 0.11.141

**Product version:** 0.11.141

**Git tag:** `v0.11.141`

В предпросмотре методиста текст теста, вопросы и варианты ответов открываются на выбранном языке курса. При возврате к уроку выбранный язык сохраняется.

Фронтенд включает общие улучшения кабинета из 0.11.140 и работает с API 0.11.140 на схеме 0192. Для отката сохраняется предыдущая рабочая сборка фронтенда 0.11.139.
