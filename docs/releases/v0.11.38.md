## Methodologist document workbench

Upload a document, wait for its index, describe the desired course, review and edit
the suggested parameters, then inspect the server-owned preview before explicitly
confirming creation. The command creates a draft through the existing course
generation pipeline; it does not publish or assign the result automatically.

The preview binds the actor, tenant, source version and content digest and expires
after15minutes. Reopening a submitted plan returns its original job; repeating
confirmation does not submit a second generation job. Changed or unavailable
sources require a new preview. Each generated result still requires review.

Editing the instruction during an upload no longer interrupts indexing or hides
the completed source. The interpreter receives the authoritative parameter schema
so format and source-strategy values are not guessed as free-form prose; invalid
provider values remain rejected rather than silently repaired.

Contextual help covers both assignment and document-to-draft workflows in Russian,
Kazakh and English, including manual parameters, confirmation and same-job reopening.

Document-workbench controls also follow the selected RU/KK/EN interface language;
switching it preserves active uploads and command state. Instructions and course
content are not silently translated.

Assessment review now detects a lesson quiz that can be passed by choosing only
uniquely-longest answers. It uses the existing bounded repair, preserves the
source-owned key and marks unresolved signals as requiring review, including
signals exposed by deduplication. Duration classification matches whole units,
not similar words such as «частичная», «деньги» or «дневник».

## Compatibility and rollout

- Additive schema0175; existing learning and assignment records are preserved.
- Both workbench and document-draft flags must explicitly permit activation.
- DEV V4/native schema3 packets bind the requested flags; build-config2 binds the
  frontend flags to immutable bundle/manifest identity.
- The privileged frontend helper, its exact eight-field manifest, provider plans,
  deployment resources and permissions are unchanged.
- Rollback disables document activation and restores the verified previous
  application release without dropping document-plan metadata.

## Not included

Voice input, speech-quality improvements, source-grounded lesson corrections,
autonomous execution/publication and changes to assignment semantics.
