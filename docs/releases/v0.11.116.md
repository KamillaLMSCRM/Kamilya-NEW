# Release Notes — 0.11.116

**Product version:** 0.11.116
**Git tag:** `v0.11.116`

ENG-073: штатная проверка исходника использует один механизм восстановления
невалидного JSON для обычных и managed-провайдеров. Только после полностью
полученного ответа допустимо одно уточнение формата на весь документ.
Содержание исходника и требования к смысловой проверке сохраняются.

Исходный ответ, уточнённый запрос, завершённые этапы и расход остаются в журнале.
Повторное чтение завершённых запросов использует сохранённые ответы. Таймаут,
неизвестный исход и ошибки самого запроса не запускают автоматический повтор.

Миграций, изменений моделей, уровней рассуждений, маршрутизации и тарифов нет.
Клиентские документы, курсы и результаты сотрудников в обновление не входят.
LOCAL/DEV/production evidence фиксируется отдельно в текущем handoff и ledger;
release notes сами по себе не доказывают успешное развёртывание.
