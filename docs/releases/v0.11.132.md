# Release Notes — 0.11.132

**Product version:** 0.11.132

**Git tag:** `v0.11.132`

Методист может добавить вопрос «Сопоставление пар» в тест курса или самостоятельную проверку знаний. Обучающийся выбирает соответствие для каждого пункта. Каждый вариант можно использовать один раз. Баллы начисляются, когда все пары верны.

При пересдаче порядок вариантов меняется. Обновление страницы восстанавливает выбранные пары текущей попытки в тесте курса. В самостоятельной проверке восстанавливаются ответы, записанные кнопкой «Сохранить ответы».

Выпуск использует действующую production-схему 0192. Прежний образ 0.11.131 подходит для отката. В предыдущей версии прохождение новых вопросов на сопоставление недоступно до повторного переключения на 0.11.132.
