# Release Notes — 0.5.53

**Product version:** 0.5.53

**Git tag:** `v0.5.53`

**Date:** 2026-09-16

## Для клиентов

- Общие вопросы о самом уроке или исходном материале не сохраняются в тест:
  проверяются конкретные факты, а непригодный вопрос удаляется без искусственного
  добора количества.
- Служебные инструкции генератора не попадают в текст урока: такой ответ модели
  отклоняется и запрашивается заново по тем же подтверждённым сведениям.
- После последнего теста обучающийся остаётся в своей сессии и возвращается в
  курс для итогового подтверждения обучения.

## Надёжность разработки

- Локальный unit-прогон больше не пытается подключиться к несуществующей БД.
  Интеграционные проверки выполняются только при явно переданном одобренном URL;
  изолированная БД CI остаётся обязательной для полного release gate.

## Проверка кандидата

- Точные дефекты сначала воспроизведены падающими регрессиями активного V2 и
  финального пользовательского перехода.
- API unit: 1 762 теста — PASS.
- Web: 595 тестов — PASS; TypeScript — PASS; production build — PASS.
- Python quality baseline: Ruff и mypy — без новых нарушений.
- После immutable-развёртывания обязательна повторная приёмка полного потока в
  синтетическом тенанте, включая загрузку подписанного скана реальным тестовым
  методистом без superadmin impersonation.

## Откат

- Откат возвращает единый backend image версии 0.5.52 для API и трёх workers и
  предыдущий immutable frontend deployment.
- Миграций базы данных в этом выпуске нет.
