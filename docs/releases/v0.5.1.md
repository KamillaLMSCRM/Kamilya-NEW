# Release Notes — 0.5.1

**Release date:** 2026-09-11
**Product version:** 0.5.1
**Git tag:** `v0.5.1`

## Customer-visible changes

- Long course generation no longer loses its continuation path when the worker
  reaches its execution time limit after saving completed lessons or tests.
- Affected generation can continue from its saved progress instead of starting
  the completed work again.

## Compatibility

- No database migration is required; schema revision remains `0158`.
- Ordinary failed generation jobs remain terminal. Recovery is limited to an
  interrupted job or the exact earlier timeout state with valid checkpoints.
- Existing courses and source documents are unchanged.
