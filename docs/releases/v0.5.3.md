# Release Notes — 0.5.3

**Release date:** 2026-09-12
**Product version:** 0.5.3
**Git tag:** `v0.5.3`

## Customer-visible changes

- A large spreadsheet with several worksheets can now be used without a
  mandatory instruction: Kamilya identifies the main learning table and treats
  auxiliary lists as supporting material instead of building the course around
  them.
- An optional description remains available when the methodologist wants to
  specify the audience, purpose, or emphasis of the course. Leaving it blank
  still produces an adaptive course from the usable source material.
- Structured spreadsheet courses keep related product or catalog attributes
  together and avoid padding a small source or over-expanding a large reference
  sheet.
- Generated tests use lesson facts and reject generic questions such as asking
  what the lesson or course is about. Repeated, unsupported, and low-information
  answer variants are rejected before the draft is saved.

## Safety and compatibility

- Generated courses and tests remain drafts for methodologist review before
  publication.
- Existing courses, source documents, tenant limits, provider order, and
  authentication behavior are unchanged.
- No database migration is required; schema revision remains `0158`.
