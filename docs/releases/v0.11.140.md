# Release Notes — 0.11.140

**Product version:** 0.11.140

**Git tag:** `v0.11.140`

В редакторе можно просмотреть утверждённые переводы уроков и структуры курса. «Открыть как обучающийся» сохраняет выбранный язык. Язык можно изменить и в самом предпросмотре.

Из карточки сотрудника журнал открывается по этому сотруднику, включая сводку и экспорт. В назначениях добавлены фильтры по должности и учебной группе и ссылка на список групп.

Выпуск использует действующую схему 0192. Откат предусмотрен к API 0.11.136 и фронтенду 0.11.139.
