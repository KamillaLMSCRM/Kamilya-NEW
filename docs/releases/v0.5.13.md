# Release Notes — 0.5.13

**Product version:** 0.5.13
**Git tag:** `v0.5.13`
**Date:** 2026-09-12

## Для клиентов

- Повторная индексация больших Excel-файлов устойчивее к кратковременному
  замедлению локальной модели: повторяется только неудачный пакет, а уже
  выполненная часть попытки не пересчитывается без необходимости.
- В рамках одной попытки используются векторы только одной модели; данные
  разных embedding-пространств не смешиваются.

## Технические изменения

- Размер пакета Qwen ограничен 16 фрагментами.
- Тайм-аут одного запроса Qwen увеличен до 30 секунд.
- Для временных сетевых задержек включены две ограниченные повторные попытки.

## Приёмка выпуска

- Профильные и общие автоматические тесты должны пройти до выпуска.
- На выделенном полном Excel проверяется индексация всех 1076 фрагментов.
- После production-развёртывания повторяется полный пользовательский путь:
  загрузка/распознавание существующего файла, переиндексация, генерация курса,
  проверка уроков и тестовых вопросов в кабинете методиста.
