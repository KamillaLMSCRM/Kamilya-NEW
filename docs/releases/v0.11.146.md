# Release Notes — 0.11.146

**Product version:** 0.11.146

**Git tag:** `v0.11.146`

Движок сохраняет доступ к всем строкам согласованного каталога и подгружает полный текст по мере необходимости. Редактор применяет адресные правки к урокам и тестам. Добавление нового урока проверяется по тому же контракту, который использует редактор.

Схема 0194 добавляет два параметра в существующий каталог runtime_settings.
