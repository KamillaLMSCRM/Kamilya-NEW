# Release Notes — 0.5.27

**Product version:** 0.5.27
**Git tag:** `v0.5.27`
**Date:** 2026-09-13

## Для клиентов

- Отсканированные PDF без текстового слоя снова можно загрузить, распознать и
  использовать как источник для создания курса.
- Окно редактирования урока стало заметно шире. Исходный текст и его итоговый
  вид показаны рядом, поэтому длинные материалы и таблицы легче проверять.
- В предпросмотре заголовки, списки и таблицы отображаются как обычный учебный
  материал: служебные символы Markdown (`#`, `| --- |`) сотруднику не видны.

## Технические изменения

- В образ Docling добавлены системные библиотеки для headless OpenCV.
- Кэш моделей перенесён в постоянный закрытый каталог `/var/lib/docling` под
  непривилегированным UID/GID `10001:10001`.
- Ключ вызова Docling одинаков для сервиса и документного worker; публичным
  остаётся только health-check, а конвертация требует защищённый заголовок.
- Схема БД и данные организаций не изменяются.

## Проверка выпуска

- Реальный 21-страничный скан правил ломбарда прошёл OCR и индексацию в
  production: 99 фрагментов, итог `completed / 100%`.
- Целевые тесты Docling проверяют non-root запуск, обязательные системные
  зависимости, постоянный кэш и fail-closed авторизацию.
- Тесты редактора подтверждают широкий диалог, безопасный форматированный
  предпросмотр заголовков и таблиц, сохранение исходного Markdown и обработку
  ошибки сохранения без закрытия окна.

## Откат

Frontend и API откатываются на неизменяемые артефакты версии `0.5.26`. Для
Docling сохранён предыдущий образ и отдельные резервные копии runtime compose;
изменений БД для отката нет.
