# Release Notes — 0.4.4

**Release date:** 2026-09-10

**Product version:** 0.4.4

**Git tag:** `v0.4.4`

## Надёжнее создаются курсы из больших Excel-каталогов

- Kamilya заранее ограничивает объём карты тем для всего исходного файла, а не
  только для каждой его части по отдельности.
- Если отдельная часть возвращает слишком длинный перечень тем, выполняется одна
  контролируемая попытка сократить формулировки без удаления источников.
- Исходные фрагменты и их привязка сохраняются; лимиты моделей, количество
  параллельных запросов и настройки организаций не изменяются.

Черновик курса и созданные тесты по-прежнему требуют проверки методистом перед
публикацией.
