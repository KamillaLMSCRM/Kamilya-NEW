# Release Notes — 0.11.13

**Release date:** 2026-09-28

**Product version:** 0.11.13

**Git tag:** `v0.11.13`

## Added

- A deterministic corporate-readiness acceptance runner now verifies the
  complete synthetic assignment, learner completion, signed-copy,
  evidence-export and reassignment lifecycle with bounded cleanup.
- The same lifecycle is defined as a machine-readable critical journey so
  release checks cannot silently omit a required stage.

## Changed

- DEV responsibility checks now load their explicit environment before API
  imports instead of depending on ambient process state.

## Fixed

- Reassigning a completed historical course now recovers a defensible access
  window from retained absolute-only policies while preserving the previous
  immutable completion history.
- The assignment screen now displays the canonical API message before a legacy
  fallback detail, giving methodologists the actionable failure reason.

## Verification

- The complete corporate DEV acceptance passed in 429.782 seconds: 10 local
  contracts, 9 DEV database contracts, signed-copy RLS, reassignment RLS,
  responsibility and 24 training-log checks; every mutable stage cleanup
  passed with zero customer writes and zero provider or billing changes.
- Focused API checks passed 67 tests with 9 skipped; the complete manual
  reassignment integration set passed 10 tests.
- Focused frontend checks passed 70 tests; the assignment UI set passed 14
  tests. Ruff, ESLint, TypeScript and Python compilation gates passed.
- The release-mode version validator and release-contract gate are required
  before publication of this release.

## Operations

- Database migration: none.
- Runtime rollout: existing free-tier DEV services, then production API and
  three workers plus the native CT137 frontend on one exact release identity.
- Rollback: the independently read-back `0.11.12` API image and CT137 release
  remain the immediate rollback targets.
- No provider plan, billing, DNS, customer tenant or customer document change
  is required.
