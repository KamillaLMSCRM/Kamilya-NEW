# Release Notes — 0.5.49

**Product version:** 0.5.49

**Git tag:** `v0.5.49`

**Date:** 2026-09-15

## Для клиентов

- Большие Excel-файлы и объёмные нормативные документы проходят через новый
  evidence-first механизм: сначала система определяет подтверждённые сведения и
  структуру курса, затем создаёт полный редактируемый черновик и тесты.
- Количество уроков и вопросов теперь определяется содержанием источника. Система
  не добавляет слабые или повторяющиеся вопросы только ради заданного количества.
- Если результат получился неполным, общим или содержит неподтверждённые сведения,
  он не сохраняется как успешно созданный курс.
- В ходе генерации отображаются фактический прогресс, активная embedding-модель
  и номер попытки провайдера, поэтому переключение резерва не выглядит как
  необъяснимый сброс счётчика.

## Надёжность

- Основной многоязычный embedding-маршрут использует совместимую семью Voyage V4:
  `voyage-4-lite -> voyage-4 -> voyage-4-large`. Затем доступны три приватные
  Qwen-реплики и Cohere.
- Поисковые запросы одного курса выполняются пакетно. Векторы разных несовместимых
  семейств не сравниваются.
- Недоступность embeddings не удаляет сведения исходного документа: внутренняя
  retrieval-проверка помечается как degraded, а grounded-генерация продолжает
  работать по подтверждённому источнику.
- Если все генеративные модели недоступны, source-only fallback сохраняется как
  редактируемый черновик, но каждый такой урок явно получает статус
  `needs_review` и не выдаётся за проверенный моделью результат.
- Отмена задания повторяемо освобождает зарезервированную квоту и AI-бюджет даже
  после временной ошибки cleanup.

## Ограничения и откат

- Миграций БД нет. Публикация и назначения курсов не меняются; результат остаётся
  черновиком для проверки методистом.
- Откат возвращает единый backend image версии 0.5.47
  (`fe56431e5551774cbdd8a1e644ecaef42d6614dc`) для API и трёх workers.
  Frontend возвращается к предыдущему CT137 release artifact, который
  фиксируется штатным deploy helper до переключения версии.
