# Release Notes — 0.11.10

**Release date:** 2026-09-27

**Product version:** 0.11.10

**Git tag:** `v0.11.10`

## Fixed

- Open learning-action cards now show their saved due date in the active
  interface locale.
- Actions owned by the signed-in methodologist now identify that responsibility
  directly on the card without exposing another user's identity.
- The due-date field continues to send a timezone-aware ISO value to the API,
  while actions without a deadline remain valid.

## Verification

- Focused learning-action frontend contracts pass for rendering the deadline,
  showing the current owner and submitting the date.
- The complete frontend suite, strict lint, typecheck and production build pass.
- DEV exact-SHA acceptance created, persisted, displayed and closed a synthetic
  action with a deadline, with zero browser console errors or warnings.
- Exact-SHA CI, native frontend build, CT137 readback and production synthetic
  browser acceptance are release gates for this patch.

## Operations

- Database migration: none.
- Backend and worker deployment: not required; their API contract is unchanged.
- Deploy only the native production frontend on CT137 from the exact release
  artifact, preserving the current release as rollback.
- No provider plan, billing, DNS, database or customer-data change is required.
