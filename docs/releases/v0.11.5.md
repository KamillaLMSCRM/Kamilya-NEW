# Release Notes — 0.11.5

**Release date:** 2026-09-25

**Product version:** 0.11.5

**Git tag:** `v0.11.5`

## Changed

- Evidence V2 keeps every valid question and explicitly omits a weak axis after
  its bounded review/repair cycle. An omission no longer poisons coverage for a
  mixed source block, but provider failures, incomplete audits, unassessed
  lessons and blocks without any accepted question remain hard stops.

## Fixed

- A source-grounded deterministic fallback that exceeds the lesson word limit
  is split at source-fact boundaries. Every derived part retains exact evidence,
  stable identity and source traceability; no synthetic padding is added.
- Production diagnostics can read one exact recent generation job error class
  through the allowlisted remote helper without returning raw container logs.
- GitHub release commands from managed worktrees resolve the canonical project
  credential path and cannot silently inherit a different ambient account.

## Verification

- Exact original Lombard PDF replay through the production Docling converter,
  Voyage embeddings and the production-shaped DeepSeek route produced ten
  lessons and nineteen reviewed questions. All ten required topics were covered,
  every lesson had a test, and the final publishability gate passed.
- The fixed PDF output was byte-identical before and after the coverage-status
  correction; only the false review status changed.
- Full local API suite: 2856 passed, 500 environment-bound tests skipped and no
  failures. Related Evidence V2, semantic assessment, completion and safe-remote
  suites: 193 passed. Additional Git credential helper tests: three passed.
- Full CI, immutable image, DEV acceptance, production deployment and two
  original-file production journeys remain release gates.

## Operations

  manifest changes.
- Required production services: API, worker-ops, worker-documents and worker-ai
