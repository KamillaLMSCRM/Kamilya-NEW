# Release Notes — 0.11.41

Product version: 0.11.41. Tag: v0.11.41. Date: 2026-10-08.
Status: CANDIDATE; publication and runtime evidence are recorded separately in
docs/PRODUCTION_READINESS.md, not inferred from these notes.

## Four bounded demo fixes

- Personal-link/PIN programme steps expose server-derived can_open and
  access_scope. Enrollment lookup binds enrollment ID, tenant ID and user ID.
  A programme read does not create other enrollments for a course-bound session.
  Foreign steps show an account-access explanation, not a Start/Review link.
  The individually assigned course remains accessible through My courses.
- Manual quiz submission requires all actual questions to have nonempty answers.
  Timer expiry still submits the available answers; clearing a multiple-choice
  selection does not count it as answered.
- My courses filters wrap on mobile screens.
- Programme audience count follows fresh assignment data and excludes cancelled
  assignments without discarding completed assignments.

## Compatibility and preserved scope

API/threeworkers and native CT137 frontend are release targets. Response fields
are additive; course guards and PIN authentication are not broadened. Ordinary
account access and programme sequencing remain unchanged. Existing0178 schema,
all three enabled workbench/document/correction flags, retained QA history and
previous release rollback are preserved. No migration, voice, antivirus, landing,
mail, resources, tiers, billing, DNS or permission changes are part of this release.

Local tests, CI, immutable images/native artifact, exact runtime readback and
changed-flow browser acceptance remain required before calling it released.
