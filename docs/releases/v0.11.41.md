## Four bounded demo fixes

- Personal-link/PIN programme steps expose server-derived can_open and
  access_scope. Enrollment lookup binds enrollment ID, tenant ID and user ID.
  A programme read does not create other enrollments for a course-bound session.
  Foreign steps show an account-access explanation, not a Start/Review link.
  The individually assigned course remains accessible through My courses.
- Manual quiz submission requires all actual questions to have nonempty answers.
  Timer expiry still submits the available answers; clearing a multiple-choice
  selection does not count it as answered.
- My courses filters wrap on mobile screens.
- Programme audience count follows fresh assignment data and excludes cancelled
  assignments without discarding completed assignments.
