# Release Notes — 0.11.90

**Product version:** 0.11.90
**Git tag:** `v0.11.90`

The author response passed validation in DEV89, but checkpoint finalization failed because an immutable tuple in its custody receipt became a JSON array after database serialization. The receipt now uses JSON values before persistence. Strict readback equality, original response custody, source identity and semantic validators are preserved.

The existing retained-response continuation supports this exact focused V36 author finalization failure. It checks the original owned claim and complete private response, absence of a persisted result, V36 policy, source and route, current wire request, response hashes and delivery authorization. Replaying the completed response sends no new author request. Other unknown outcomes and unapproved/foreign state remain held. The old interrupted job and its evidence are not relabelled successful by a code change.

Local JSON-roundtrip regressions first reproduced the failure; a SELECT-only check through the actual DEV worker/database codec confirms the same type conversion. Saved-case tests, native DEV continuation/full-course acceptance and protected production/live acceptance are separate evidence stages.

This is a no-migration backend successor to the unaccepted DEV89 candidate. It retains the addressed model corrections and source-decision context from that package. It does not claim reliable blind rediscovery of every semantic defect. Customer courses, assignments, history, provider plans, model routing, reasoning level, voice and reserve configuration are unchanged. The separately accepted native production frontend remains its existing revision.
