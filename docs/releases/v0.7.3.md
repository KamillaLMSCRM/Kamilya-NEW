# Release Notes — 0.7.3

**Product version:** 0.7.3

**Git tag:** `v0.7.3`

**Date:** 2026-09-19

## Для клиентов

- Тесты формируются внутри смыслового блока урока: неверные варианты относятся
  к тому же вопросу, а не подставляются из соседних тем документа.
- Количество уроков и вопросов по-прежнему зависит от полезной информации в
  источнике. Невалидные и повторяющиеся вопросы удаляются без искусственного
  заполнения заданной квоты.
- Условия, исключения и необязательные действия сохраняют исходный смысл.
  Система отклоняет варианты, которые превращают «не требуется» в запрет или
  обязанность.
- Если безопасный тест к части материала сформировать не удалось, сам курс
  остаётся доступным черновиком. Методист получает понятное действие
  «Открыть сохранённый черновик», а не повторный запуск завершённой генерации.

## Контроль качества

- Каждый вопрос связан с одной проверяемой характеристикой источника и проходит
  отдельную проверку ключа, вариантов ответа, практической правдоподобности и
  покрытия тем урока.
- Для однозначных правил допустимы серверные вопросы «верно/неверно» с ключом,
  который не отдаётся на усмотрение генеративной модели.
- TypeSafe и дополнительные оценочные сценарии остаются только инструментами
  разработки. Они не входят в клиентский поток и не получают документы tenant-а.
- Локальная PDF-приёмка использует тот же Docling-конвертер, что production, и
  завершается ошибкой конфигурации, если этот маршрут недоступен.

## Проверка релиза

- Полный database-free API unit suite: `2028 passed`; итоговая выборка
  constraint/practical-quality: `33 passed`; Ruff и `git diff --check` прошли.
- Frontend: `115` файлов и `619` тестов, TypeScript и lint прошли.
- Полный Excel «Плюса»: 3 урока, 8 принятых вопросов из 9 кандидатов, покрытие
  3/3 тем, без непроверяемых уроков, fallback и ошибок; результат publishable.
- Полный PDF ломбарда после production-equivalent Docling: 15 уроков,
  30 вопросов, покрытие 13/13 тем, без fallback; результат publishable.
- Независимая проверка Excel не выявила неверных ключей, нерелевантных вариантов,
  неоднозначности, неподтверждённых утверждений или повторов между уроками.

## Развёртывание и откат

- Миграция не требуется; схема production database не меняется.
- Одним immutable release обновляются API и три worker. Native frontend получает
  ту же exact-SHA версию с новым состоянием сохранённого черновика.
- Откат приложения и frontend выполняется на immutable release 0.7.2; данные и
  схема БД не меняются.
