# Release Notes — 0.11.26

**Product version:** 0.11.26
**Git tag:** `v0.11.26`
**Date:** 2026-10-02

Подготовлен совместимый первый этап выпуска рабочего места методиста. Миграция
0169 добавляет ограниченные функции поиска организации, необходимые обновлённому
API, но ещё не включает строгие политики0170/0172. API и worker обновляются с
рабочим местом выключенным. Это промежуточный этап, не завершённый запуск функции.

Перед следующим этапом требуется независимая проверка входа, постоянного
QA-стенда, идентичности API/worker и явно выключенных флагов. Только затем
применяются0170–0172 и проверяется финальная изоляция. Откат приложения после
ужесточения остаётся на совместимом бинарном релизе; широкие политики и старый
несовместимый API не восстанавливаются.

В изолированной схеме Supabase DEV проверены существующие политики, внешние
ключи, триггеры, права функций, назначения, приглашения, конкурентные запросы
и правила хранения. Тестовая схема удалена, публичная схема не изменена.
Это не заменяет приёмку публичного DEV и production.

Статус: кандидат подготовлен, production rollout NOT ACCEPTED. Голосовой ввод,
LLM-интерпретация, генерация документов, отправка писем и запуск фоновой очистки
не включаются этим совместимым этапом. Точный runtime SHA и итоговая приёмка
публикуются отдельно в PRODUCTION_READINESS.md после проверенного выпуска.
