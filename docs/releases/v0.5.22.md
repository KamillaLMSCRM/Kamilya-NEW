# Release Notes — 0.5.22

**Product version:** 0.5.22
**Git tag:** `v0.5.22`
**Date:** 2026-09-13

## Для клиентов

- Kamilya удаляет слабый или повторный вопрос вместо создания замены только ради
  запланированного количества.
- Вопрос по таблице должен прямо называть коллекцию, товар или другой предмет
  проверки; формулировки вроде «что указано в описании» больше не принимаются.
- Вопрос не принимается, если его текст уже подсказывает большую часть правильного
  ответа.
- Количество уроков и вопросов остаётся верхней границей. Небольшой или бедный
  фактами источник может дать более короткий, но содержательный курс.

## Технические изменения

- Расширена проверка конкретного предмета вопроса для структурированных источников.
- Добавлена проверка частичного раскрытия длинного правильного ответа в вопросе.
- Новые ошибки включены в путь удаления без повторного обращения к модели.
- Схема БД, пользовательские данные и интерфейс не изменяются.

## Проверка выпуска

- Новые RED-регрессии воспроизвели обе формулировки из production-курса до
  исправления и прошли после него.
- Интеграционный unit-сценарий подтверждает: из трёх вопросов остаётся один
  качественный, а модель вызывается ровно один раз — без скрытого дополнения квоты.
- Связанный assessment-набор, полный API unit-набор, version gate, exact-SHA CI,
  production deployment и повторная генерация полного Excel являются обязательными
  gate выпуска.

## Откат

API откатывается на неизменяемый backend-артефакт `0.5.21`. Изменений БД и
frontend-кода в выпуске нет.
