# Release Notes — 0.5.34

**Product version:** 0.5.34

**Git tag:** `v0.5.34`

**Date:** 2026-09-14

## Для клиентов

- Большой документ больше не должен прерывать генерацию в момент, когда первый
  вариант урока требует автоматического исправления качества.
- При повторной попытке Kamilya сохраняет факты и ссылки на исходный документ,
  но уменьшает только объём переданного фрагмента, чтобы вместе с замечаниями
  проверки уложиться в технический лимит модели.
- Количество уроков остаётся верхней границей: слабые уроки не дополняются ради
  плана, а весь курс сохраняется только при наличии достаточного полезного ядра.

## Технические изменения

- Writer заново рассчитывает сериализованный prompt budget для каждой
  quality-retry с учётом фактического текста коррекции.
- Исходные кандидаты остаются неизменными; каждый retry повторно выполняет
  ограниченный отбор и сохраняет представление всех запрошенных документов.
- Невмещающиеся метаданные и невозможность представить каждый документ
  по-прежнему завершаются безопасной ошибкой до вызова провайдера.
- Схема БД и данные организаций не изменяются.

## Проверка выпуска

- RED-регрессия воспроизводит production-сбой: начальный prompt заполнен до
  лимита, первая версия урока отклонена, а коррекция переполняет второй запрос.
- GREEN выполняет обе попытки внутри 32 000 символов, сохраняет correction
  instruction и возвращает урок с исходными ссылками.
- После exact-SHA deployment повторяются полные production-пути по PDF правил
  ломбарда и должностной инструкции `.doc`, включая замеры стадий и визуальную
  проверку редактора.

## Откат

API и frontend откатываются на неизменяемые артефакты версии `0.5.33`.
Изменений БД для отката нет.
