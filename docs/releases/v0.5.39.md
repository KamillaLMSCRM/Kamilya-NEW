# Release Notes — 0.5.39

**Product version:** 0.5.39

**Git tag:** `v0.5.39`

**Date:** 2026-09-14

## Для клиентов

- Создание курса больше не прерывается из-за слишком подробного служебного
  резюме документа: оно автоматически и предсказуемо сокращается до допустимого
  размера.
- Найденные темы при этом сохраняются полностью и продолжают использоваться для
  проектирования курса.

## Технические изменения

- Вспомогательный summary нормализуется и ограничивается точным остатком
  content budget с обрезкой по границе слова.
- Жёсткие лимиты полного ответа, массива тем, токенов и финального обзора не
  ослаблены.
- Протокол source map повышен до `v6`; схема БД остаётся `0159`.

## Проверка выпуска

- RED/GREEN-регрессия воспроизводит summary длиной около 2,800 символов и
  подтверждает результат не более 1,600 символов без потери трёх тем.
- Отдельная регрессия сохраняет повтор модели для полного ответа свыше 8,000
  символов; профильный source-map/failover gate проходит 70 тестов.
- После exact-SHA deployment повторяется полный production-путь методиста по
  документу ломбарда с замерами и анализом курса/тестов.

## Откат

Приложение откатывается на неизменяемые артефакты `0.5.38`; миграций БД нет.
