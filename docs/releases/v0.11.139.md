# Release Notes — 0.11.139

**Product version:** 0.11.139

**Git tag:** `v0.11.139`

Действие «Дублировать блок» вставляет копию сразу после выбранного блока. Копию можно редактировать отдельно.

Команды «Отменить действие» и «Повторить действие» работают с изменениями содержания активного черновика. При переходе в предпросмотр история доступна после возврата в редактор. После успешного сохранения отсчёт начинается с сохранённой версии.

Фронтенд использует действующий API 0.11.136 и схему 0192. Для отката сохранена сборка фронтенда 0.11.138.
