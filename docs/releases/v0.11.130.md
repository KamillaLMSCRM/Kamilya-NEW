# Release Notes — 0.11.130

**Product version:** 0.11.130

**Git tag:** `v0.11.130`

Методист может добавить в урок фрагмент YouTube и необязательный вопрос по таймкоду. Для двуязычного урока сохраняются обе версии вопроса. Обучающийся получает пояснение после ответа, может пропустить вопрос и продолжить просмотр. Оценка курса и попытки тестирования от самопроверки не зависят.

Выпуск использует действующую production-схему 0192. Для отката подходит 0.11.129 с той же схемой.
