# Release Notes — 0.4.1

**Release date:** 2026-09-10

**Product version:** 0.4.1

**Git tag:** `v0.4.1`

## Генерация из больших таблиц

- Устранён преждевременный отказ при подготовке курса из больших Excel-файлов с повторяющимися заголовками.
- Служебные сведения об источнике передаются компактнее; содержимое исходных фрагментов и проверки их полноты сохраняются.

Материалы курса и тестов остаются редактируемыми черновиками для проверки перед публикацией.
