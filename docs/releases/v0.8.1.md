# Release Notes — 0.8.1

**Release date:** 2026-09-21
**Product version:** 0.8.1
**Git tag:** `v0.8.1`

## Summary

This patch completes language continuity in the public learning example. A
visitor who opens the example in English now keeps English when moving to
registration, the demo workspace or sign-in, and the accessibility skip link
uses the same selected language.

## Fixed

- Preserve `lang` on all calls to action and the logo link from the public
  learning example.
- Synchronize the example language with global interface and accessibility
  translations.
- Add regression coverage for localized links and skip-to-content copy.

## Security and deployment

- Database migrations: not required.
- Environment variables: no new variables.
- No secret, billing, DNS, storage or tenant-isolation changes.
- Deploy the same immutable API/worker image and native cabinet artifact from
  the exact `v0.8.1` commit; the landing remains a separately identified CT137
