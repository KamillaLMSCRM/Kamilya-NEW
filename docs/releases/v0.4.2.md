# Release Notes — 0.4.2

**Release date:** 2026-09-10

**Product version:** 0.4.2

**Git tag:** `v0.4.2`

## Курсы из больших Excel-каталогов

- Исправлены сбои при подготовке курса из объёмных таблиц с длинными заголовками.
- При составлении плана обрабатываются материалы по всему документу, включая его
  последние разделы. Содержание конкретных уроков подбирается по их темам.
- Некорректный формат служебного ответа модели обрабатывается ограниченной
  повторной попыткой внутри текущего задания.

## Читаемые материалы уроков

- Заголовки, списки и простые таблицы отображаются в оформленном виде, а не как
  текст с символами разметки.
- Встроенный в материал HTML не выполняется.

Курс и тесты сохраняются как редактируемые черновики. Перед публикацией методист
проверяет факты, формулировки и правильные ответы. Генерация не означает, что
каждая строка каталога включена в учебную программу.
