# Release Notes — 0.11.134

**Product version:** 0.11.134

**Git tag:** `v0.11.134`

Справка в кабинете методиста дополнена шагами настройки тренажёра решений, подбора вопроса по видео, выбора языков курса и создания вопросов на порядок действий и сопоставление пар.

В видеоинструкции появились два коротких ролика с озвучкой и субтитрами. Они показывают настройку тренажёра и подбор вопроса по таймкоду из файла субтитров.

Выпуск обновляет веб-интерфейс. API 0.11.133 и схема 0192 продолжают работу. Для отката веб-интерфейса подходит 0.11.133.
