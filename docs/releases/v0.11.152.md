# Release Notes — 0.11.152

**Product version:** 0.11.152

**Git tag:** `v0.11.152`

- Production worker topology adds one bounded AI consumer and one bounded document-processing consumer on the existing shared queues. The operations/notifications worker remains the sole Celery beat owner. The release plane drains one slot before starting the other, restores the previous consumer set on failure, and selects the legacy three-worker topology when rolling back to a version before 0.11.152.

- No database migration or new paid infrastructure is required.
