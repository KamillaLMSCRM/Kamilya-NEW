# Release Notes — 0.11.143

**Product version:** 0.11.143

**Git tag:** `v0.11.143`

В каталоге курсов доступны утверждённые переводы названий и описаний. Поиск учитывает исходное название и утверждённый перевод.

«Задания генерации» открывают историю, а «Создать из документов» начинает подготовку нового курса. Markdown доступен через «Ещё» в редакторе урока. Для вопроса с одним правильным ответом используется локализованная подпись.

Схема 0192. Миграция не требуется.
