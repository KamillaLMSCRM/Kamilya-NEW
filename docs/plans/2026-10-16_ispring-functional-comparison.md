## Пакет 1: visual-lesson-editor V1 — замороженный контракт

Approved by: владелец, прямое поручение 2026-11-15. Root отвечает за модуль,
интеграцию, QA и выпуск. Планирование/проверки/приёмка root; независимые ожидаемые
результаты задаются поведенческими тестами и живым readback. Изменение объёма
фиксируется здесь до изменения интерфейса. Это frontend consumer-only пакет.

Результат: методист собирает урок из видимых блоков и сохраняет его обычной
кнопкой; ученик видит тот же материал через существующий LessonContent.
Модуль `VisualLessonEditor` владеет только временной компоновкой. Интерфейс:
`value: string`, `onChange(string)`, `lang`, `disabled`. Блоки: текст, заголовок,
иллюстрация с подписью из существующих разрешённых source-assets, правило
(blockquote), шаги (ordered list). Редактор Markdown остаётся доступным.

Путь: сохранённый content → lossless сегменты → выбор/правка/добавление/порядок/
явное удаление блока → существующий dirty state → существующий lesson PATCH →
повторное чтение review status → существующая проверка/публикация → LessonContent.
Состояния: сохранено, локально изменено, сохранение, ошибка с сохранённым черновиком,
сохранено с актуализированным review status. Переключение режимов не сохраняет.

Инварианты: открытие, выбор блока и переключение режимов сохраняют исходную строку
побайтно; неизвестный Markdown/таблицы/код/CRLF не удаляются и не преобразуются
автоматически. Изменение одного блока не переписывает остальные. Формат хранения
остаётся Markdown, без новой таблицы/миграции/зависимости/HTML injection. Ссылки на
источник, изображения и ordinal нумерации не переписываются при открытии.
Разрешённые иллюстрации проходят прежний authenticated renderer; arbitrary URL
не добавляется новым контролом. Сохранение и source/publication/review guards,
session/tenant boundaries, исправления ассистента, вопросы и история не меняются.
Порядок меняется кнопками, доступными с клавиатуры; удаление требует подтверждения.

Не входит: изменение генератора, автоматическое перегенерирование/правка тестов,
новый upload backend, arbitrary media, аккордеоны с новым форматом хранения,
SCORM, экзамены, голос, billing/settings и правки клиентских курсов.

Проверка: lossless round-trip legacy Markdown/CRLF/таблиц/кода/source image;
точечная правка и reorder; cancel/delete/disabled/keyboard/locales; реальная
страница редактора сохраняет старый PATCH/dirty/review/session контракт;
один полный frontend suite, type/lint/build, desktop/mobile browser QA.
DEV: постоянный QA-tenant, отдельный непубликованный synthetic draft; открыть
старый материал без writes, собрать/сохранить/перезагрузить новый урок, проверить
preview и source guards. Production только после DEV GO/exact CI/artifact,
rollback-ready frontend release и независимой живой проверки QA-сценария.
API/workers/DB/customer courses сохраняются. Не вызывать модели ради UI QA.

Rollback: прежний API и основные Markdown-блоки совместимы; исходный текст и
ссылки сохраняются. Новая поддержка экранированных скобок в подписи изображения
требует113 для полного отображения; при откате старый плеер может показать такую
новую подпись как Markdown. В приёмке подобные подписи только менялись локально
и отменялись; старые опубликованные курсы не перезаписывались.
Stop: lossless regression, source/tenant/guard
изменение, непроверенный release target, неизвестный write outcome — NO_GO,
сохранить черновик/evidence и восстановить authoritative state, не повторять create.
