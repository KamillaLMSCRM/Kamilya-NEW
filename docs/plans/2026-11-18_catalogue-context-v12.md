# CHG-CONTEXT120: bounded literal source access

Owner request: reduce119's3.59M input/31min, retain complete catalogue access,
and correct weak questions through the existing model editor. Root owns the
sequential implementation/integration/release; no delegated writers. Product
authority: current owner request, conditional production after successful QA.

## Contract and owners

Existing approved source, original bytes, tenant/RLS, source pins and immutable
published courses remain authoritative. New source-access module owns only a
versioned model view and local exact lookup; it never edits source or certifies
facts. Transport owns raw-response custody, typed format, claim and checkpoint.
Existing V11 course/editor owns lesson structure, content and addressed edits.

Directed chain: approved source -> frozen literal row store -> compact navigation
index + selected literals -> existing plan/author/review/editor -> existing draft
save -> human review/publication. A model may request named literal rows through
one typed response, which the app resolves locally; it receives no arbitrary
filesystem/network/database tools. No new semantic critic, embedding service,
vector database, provider, or plan is introduced.

## Invariants

- Only explicitly supporting prepared table material is eligible for reference
  compaction. Learning prose, table headers, normative parent context and visuals
  retain literal custody; unclassified/unknown material is not silently discarded.
- Index labels are navigation, not replacement evidence. Every row remains in
  the exact tenant/document/approved-revision store and can be fetched by handle.
- Retrieval returns whole literal rows with offsets/header/source alias. Never
  cut a row to fit a budget or silently return partial requested evidence.
- Initial literal context is bounded by runtime_settings; lookup rounds have a
  finite limit. No unrelated entire catalogue fallback. Oversize/unknown/stale/
  foreign requests fail explicitly, keeping completed replies and reasons.
- New V12 request identities and closed source-access transport contract; V1–V11
  inputs/cold replays remain exact. No changed prompt is passed off as an old
  completed model reply. Old source53responses and119course remain untouched.
- Existing final operational review compares each question's actual assessed
  skill with its OWN lesson's teaching, separately from source factual truth and
  hidden scenario context. Existing scoped postedit makes the correction; good
  bodies/cards and false-positive protections remain.
- Configurable context/lookup budgets use existing runtime_settings/history,
  never new env variables or another variables table. Credentials unchanged.
